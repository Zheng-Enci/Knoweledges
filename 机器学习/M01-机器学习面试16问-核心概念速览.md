## 1. 数据划分与评估指标 📊 / Data Splitting & Evaluation Metrics

### Q1. 训练集、验证集、测试集三者的核心分工与使用禁忌 🎯

数据集划分为 Training Set（学习模型参数）、Validation Set（模型选择与超参数调优）和 Test Set（最终泛化性能评估）。Test Set 信息严禁泄露到训练过程中——预处理统计量必须只在 Training Set 上计算，时序数据需按时间顺序划分，Test Set 绝不能用于模型选择。常用的划分比例为 6:2:2 或 7:1.5:1.5，小数据集推荐使用交叉验证。

参考资料：

- [Cross Validation in Machine Learning -- GeeksforGeeks](https://www.geeksforgeeks.org/machine-learning/cross-validation-machine-learning/) ⭐值得阅读
- [3.1. Cross-validation: evaluating estimator performance -- Scikit-learn](https://scikit-learn.org/stable/modules/cross_validation.html)

### Q2. 准确率、精确率、召回率、F1 分数的适用场景与各自局限性 🎯

Accuracy = (TP+TN)/(TP+TN+FP+FN) 衡量整体正确率，但在不平衡数据上具有误导性；Precision = TP/(TP+FP) 优先避免假正例，适用于假正例代价高的场景；Recall = TP/(TP+FN) 优先避免假负例，适用于疾病筛查或欺诈检测等场景；F1 Score = 2×P×R/(P+R) 在两者间取得平衡。在类别均衡时选 Accuracy，假正例代价高时选 Precision，假负例代价高时选 Recall，需要综合评估时选 F1，极端不平衡时推荐 MCC 或 PR AUC。

参考资料：

- [Classification: Accuracy, recall, precision, and related metrics -- Google Developers](https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall)
- [Accuracy, precision, recall, f1-score, or MCC? empirical evidence -- Springer](https://link.springer.com/article/10.1186/s40537-025-01313-4) ⭐值得阅读

### Q3. ROC 曲线与 PR 曲线的核心差异，以及各自适配的数据场景 🎯

ROC 曲线以 FPR 为横轴、TPR 为纵轴，对类别不平衡不敏感（TPR 和 FPR 分别考虑了正负类），但负类占主导时可能显得过于乐观。PR 曲线以 Recall 为横轴、Precision 为纵轴，仅关注正类性能，对不平衡数据更可靠。极端不平衡（正类 < 10%）和欺诈检测等场景推荐 PR 曲线，需要全局阈值评估且统计含义清晰时选用 ROC。

参考资料：

- [ROC AUC vs Precision-Recall for Imbalanced Data -- Machine Learning Mastery](https://machinelearningmastery.com/roc-auc-vs-precision-recall-for-imbalanced-data/) ⭐值得阅读
- [The Precision-Recall Plot Is More Informative than the ROC -- PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4349800/)

## 2. 特征工程与优化算法 ⚙️ / Feature Engineering & Optimization Algorithms

### Q4. 归一化与标准化的区别、联系、适用模型与数据场景 🎯

归一化（Min-Max Scaling）通过 X' = (X−Xmin)/(Xmax−Xmin) 将数据缩放到 [0,1]，对异常值敏感；标准化（Z-Score）通过 X' = (X−μ)/σ 将数据转换为均值 0、标准差 1，对异常值更鲁棒。两者都能消除量纲影响，且统计量必须在 Training Set 上计算。标准化通常更适用于基于距离的模型和未知分布的数据，归一化适用于有界数据（如图像像素）。

参考资料：

- [Normalization vs Standardization -- Codecademy](https://www.codecademy.com/article/min-max-zscore-normalization)
- [z-score VS min-max normalization -- Stack Exchange](https://stats.stackexchange.com/questions/547446/z-score-vs-min-max-normalization) ⭐值得阅读

### Q5. 为什么 KNN、SVM 需要标准化，而决策树、集成树模型不需要？🎯

KNN 依赖距离度量，量级大的特征会主导计算；SVM 的目标函数涉及内积或核函数计算，量级大的特征会主导优化，因此两者都需要特征缩放。决策树和集成树模型基于特征值的排序和阈值比较进行分裂，而非距离计算，因此具有尺度不变性——特征的绝对量级不影响分裂决策。

参考资料：

- [Why Decision Trees Don't Need Feature Scaling -- dev.to](https://dev.to/moubarakmohame4/why-decision-trees-dont-need-feature-scaling-and-why-this-matters-91d) ⭐值得阅读
- [What algorithms need feature scaling, beside from SVM? -- Stack Exchange](https://stats.stackexchange.com/questions/244507/what-algorithms-need-feature-scaling-beside-from-svm)

### Q6. BGD、SGD、MBGD 三种梯度下降算法的优缺点与适配场景 🎯

BGD 每轮使用全部样本计算梯度，收敛稳定但需要全量数据载入内存，且难以跳出局部最优；SGD 逐样本更新，更新频繁、方差大，有助于跳出局部最优但收敛不稳定；MBGD 每次使用小批量样本（32–128 个），在精度、内存效率和并行化之间取得平衡，搭配 Adam 等自适应优化器时是深度学习的默认选择。

参考资料：

- [Batch, Mini-Batch and Stochastic Gradient Descent for Linear Regression -- Medium](https://medium.com/data-science/batch-mini-batch-and-stochastic-gradient-descent-for-linear-regression-9fe4eefa637c)
- [Gradient Descent Algorithm Survey -- arXiv](https://arxiv.org/html/2511.20725v1)

## 3. 正则化与分类模型 🧠 / Regularization & Classification Models

### Q7. 对比 L1、L2、Dropout、早停止四种正则方式的原理与适用场景 🎯

L1 正则化在损失函数中添加 λ∑|w|，产生稀疏权重，适用于特征选择；L2 正则化添加 (λ/2)∑w²，均匀地缩小权重，用于通用过拟合预防；Dropout 在训练时随机丢弃部分神经元，等效于训练子网络集成，适用于深度神经网络；Early Stopping 在验证集性能不再提升时停止训练，对所有迭代模型起到隐式正则化作用。现代深度学习通常组合使用 L2、Dropout 和 Early Stopping。

参考资料：

- [Understanding Regularization Techniques -- Medium](https://medium.com/@o.ankeli/understanding-regularization-techniques-in-machine-learning-l1-l2-dropout-data-augmentation-7a8f61b95e8f)
- [Regularization in Deep Learning: L1, L2 & Dropout -- E2E Networks](https://www.e2enetworks.com/blog/regularization-in-deep-learning-l1-l2-dropout)

### Q8. 逻辑回归 Sigmoid 函数作用与交叉熵损失的优势 🎯

Sigmoid 函数 σ(z)=1/(1+e^{−z}) 将线性输出 z=wᵀx+b 映射到 (0,1) 作为概率 P(y=1|x)；交叉熵损失 L=−(1/N)∑[y log ŷ + (1−y) log(1−ŷ)] 提供凸优化、梯度与 (ŷ−y) 成比例（避免 Sigmoid 下 MSE 的饱和问题），且具有天然的 KL 散度概率解释。

参考资料：

- [Why We Don't Use MSE Loss for Classification -- YouTube](https://www.youtube.com/watch?v=bNwI3IUOKyg)
- [Comparing MSE loss and cross-entropy loss -- Stack Overflow](https://stackoverflow.com/questions/49322197/comparing-mse-loss-and-cross-entropy-loss-in-terms-of-convergence) ⭐值得阅读

### Q9. 朴素贝叶斯的核心假设、平滑原理与三类贝叶斯算法适配场景 🎯

朴素贝叶斯假设条件独立 P(X₁,…,Xₙ|Y)=∏P(Xᵢ|Y)，该假设在现实中很少成立但表现良好，通过 Laplace 平滑 P(Xᵢ|Y)=(count+α)/(N+α×K) 防止零概率。Gaussian NB 假设连续特征服从正态分布，Multinomial NB 适用于基于词频或 TF-IDF 的文本分类，Bernoulli NB 适用于二值特征（如单词是否出现）。

参考资料：

- [Naive Bayes -- Scikit-learn](https://scikit-learn.org/stable/modules/naive_bayes.html) ⭐值得阅读
- [Naive Bayes and Text Classification I -- arXiv](https://arxiv.org/pdf/1410.5329)

## 4. 决策树与集成学习 🌲 / Decision Trees & Ensemble Learning

### Q10. 详细对比 ID3、C4.5、CART 三种决策树算法的核心差异与优劣 🎯

ID3 使用信息增益作为分裂准则，仅支持离散特征且无剪枝，倾向于选择取值多的特征；C4.5 改进为增益率以避免该偏差，支持连续特征和缺失值，采用后剪枝；CART 使用基尼系数（回归用 MSE）进行二叉分裂，配合代价复杂度剪枝，是工业标准——作为 Random Forest 和 GBDT 的基学习器。ID3 基本被淘汰，C4.5 作为学术参考，CART 是工业首选。

参考资料：

- [Decision Tree Algorithms -- GeeksforGeeks](https://www.geeksforgeeks.org/machine-learning/decision-tree-algorithms/) ⭐值得阅读
- [Performance Evaluation Among ID3, C4.5, and CART -- ResearchGate](https://www.researchgate.net/publication/348781244_Performance_Evaluation_Among_ID3_C45_and_CART_Decision_Tree_Algorithm)

### Q11. 决策树预剪枝与后剪枝的原理、优缺点与适用场景 🎯

预剪枝在树构建过程中提前停止生长（通过 max_depth、min_samples_leaf 等参数），计算成本低但可能导致欠拟合；后剪枝先生成完整树再从底部向上剪枝，利用全局信息做出剪枝决策，泛化能力更好但计算成本更高。实践中两者通常结合使用——预剪枝控制粗略规模，后剪枝精细调优。

- [Pruning Decision Trees -- GeeksforGeeks](https://www.geeksforgeeks.org/machine-learning/pruning-decision-trees/)

### Q12. 深度辨析 Bagging 与 Boosting 集成框架的训练机制、优化目标与代表算法 🎯

Bagging 通过 Bootstrap 采样并行训练基学习器，通过对预测取平均来降低方差，通常使用深度决策树等强学习器（Random Forest 在此基础上加入随机特征选择以进一步降低相关性）；Boosting 串行训练模型，每轮聚焦前一轮错误来降低偏差，使用浅层树等弱学习器，并根据性能分配权重（XGBoost/LightGBM 进一步扩展了 GBDT）。噪声数据或需要快速训练时选 Bagging，数据干净且追求最高精度时选 Boosting。

参考资料：

### Q13. SVM 硬间隔、软间隔、核函数的原理与工程适用场景 🎯

硬间隔 SVM 要求所有样本正确分类（yᵢ(wᵀxᵢ+b)≥1），不适用于真实数据；软间隔 SVM 引入松弛变量 ξᵢ 和惩罚参数 C 来控制分类严格程度。核技巧通过 K(xᵢ,xⱼ)=φ(xᵢ)ᵀφ(xⱼ) 将数据隐式映射到高维空间——线性核用于文本分类，RBF（高斯）核作为非线性问题的通用默认选择，C 和 γ 是关键超参数。

## 5. 聚类、降维与专项话题 🔬 / Clustering, Dimensionality Reduction & Special Topics

### Q14. K-Means 与 DBSCAN 的核心差异、优缺点与算法选型依据 🎯

K-Means 是基于距离的划分式聚类算法，需要预先指定 K 值，只能发现凸/球形簇，对异常值敏感且依赖初始化，但速度快、可扩展性强。DBSCAN 是基于密度的聚类算法，自动确定簇数量，能发现任意形状的簇，通过将异常点标记为噪声来鲁棒处理异常值，但在密度不均匀和高维数据上表现不佳。大数据量的球形簇场景选 K-Means，不规则形状或含噪声数据选 DBSCAN。

参考资料：

- [DBSCAN vs. K-Means: A Guide in Python -- New Horizons](https://www.newhorizons.com/resources/blog/dbscan-vs-kmeans-a-guide-in-python) ⭐值得阅读
- [Comparing DBSCAN, k-means, and Hierarchical Clustering -- Hex](https://hex.tech/blog/comparing-density-based-methods/)

### Q15. PCA 降维的核心思想、完整步骤与优缺点 🎯

PCA 通过协方差矩阵的特征值分解，将 p 维特征线性投影到 k 个正交的主成分上，捕获最大方差，标准化后执行，k 由累积解释方差（如 95%）确定。它能消除线性冗余、降低过拟合风险、加速训练，但只能捕获线性关系，且主成分是原始特征的线性组合，缺乏可解释性。

参考资料：

- [Principal Component Analysis (PCA) -- GeeksforGeeks](https://www.geeksforgeeks.org/data-analysis/principal-component-analysis-pca/) ⭐值得阅读
- [Principal Component Analysis (PCA): Explained Step-by-Step -- Built In](https://builtin.com/data-science/step-step-explanation-principal-component-analysis)

### Q16. AdaBoost 算法为什么对噪声数据敏感？🎯

AdaBoost 对噪声敏感的根本原因在于其指数损失函数 L(y,f)=exp(−y·f(x)) 对误分类样本施加指数级增长的惩罚，形成正反馈循环——噪声样本权重不断放大并主导后续学习器，加上缺乏显式正则化和确定性（而非随机性）的权重分配机制。RobustBoost 或 XGBoost 等 Gradient Boosting 方法是更鲁棒的替代方案。

参考资料：

- [Is there any formal explanation for the sensitivity of AdaBoost to outliers? -- Data Science Stack Exchange](https://datascience.stackexchange.com/questions/45813/is-there-any-formal-explanation-for-the-sensitivity-of-adaboost-to-outliers) ⭐值得阅读
