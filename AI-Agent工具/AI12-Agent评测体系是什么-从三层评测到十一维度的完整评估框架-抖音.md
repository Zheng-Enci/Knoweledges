## P01 · 封面

> 卡片职责：抛钩子 + 定锚主题，点破「Agent 评测」核心名词

- **Agent 评测体系到底是什么？**
- 副标题：评什么三层 + 怎么评十一维，看完你就懂
- 核心数字：ClawBench 实测最强 Agent 也才 **33.3%** 任务完成率

## P02 · 评测存在，是因为 Agent 看着能干

> 卡片职责：讲评测存在的原因，立起「假成功」问题

- Agent 评测体系，就是一套**判断 Agent 靠不靠谱**的方法，核心回答「评什么 + 怎么评」。
- 为什么需要它：Agent 输出的是文本、干的是行动，**回复漂亮不等于任务真完成**。
- 典型坑：Agent 说「已订票」，但票务系统里根本没订单——这叫**假成功**。
- 类比 🎭：评判 Agent 不能像批改作文看文笔，要像验收工程看墙真刷好了没 ⚡。

## P03 · 评什么：端到端、过程、能力三层

> 卡片职责：讲三层分类，搭建评测骨架

- 评测对象分三层：**端到端、过程、能力**，从整体到零件递进。
- 端到端把 Agent 当黑盒，只看任务有没有完成；过程看中间轨迹合不合理。
- 能力层拆开测单项：工具使用、记忆、规划、多 Agent 协作各测各的。
- 三层组合用：端到端给总分，过程给「哪步坏」，能力给「哪块弱」 🎯。

## P04 · 端到端：只看任务完成率

> 卡片职责：讲第一层，强调核验真实状态

- **端到端评测**最直觉：给 Agent 一个任务，跑完，比对最终结果和正确答案。
- 核心指标是**任务完成率**——完成的任务占总任务的占比。
- 关键纪律：**完成率必须核验真实系统状态**，不能信 Agent 的「已成功」自述。
- 优点全自动成本低，缺点是只看到结果、看不到过程对不对 📌。

## P05 · 过程评测：看轨迹是否合理

> 卡片职责：讲第二层，补上「过程分」

- **过程评测**检查执行轨迹：调用了哪些工具、顺序对不对、有没有无效反复。
- 核心指标是**轨迹质量**——路径合理性、效率、是否偏离目标。
- 两个 Agent 都完成时，一个直来直去、一个绕十圈——过程评测能区分它们。
- 生产调试最有用：端到端分低时，看轨迹能定位「卡在工具调用还是规划」🔍。

## P06 · 能力评测：拆开测短板

> 卡片职责：讲第三层，落到单项能力

- **能力评测**把 Agent 拆成零件逐个测：工具使用、规划推理、记忆、自主性、协作。
- 它的价值是**定位短板**：总分低时，告诉你「是工具用不好还是记不住事」。
- 对应选型：架构定了之后，用能力评测确认每个角色真能胜任（可回看本专栏架构篇）。
- 三层合起来才是完整体系：**总分 + 过程 + 能力**三张表一起看 ✅。

## P07 · 怎么评：十一维评测框架

> 卡片职责：讲十一维体系，给全面评估维度

- 一份评测综述提出**十一维评测体系**：任务成功、输出质量、规划、工具、自主性、安全、效率等。
- 它覆盖 Agent 的方方面面，是「完整评测」的理想框架。
- 但实际项目**不必全测**——按场景挑几个关键维度即可。
- 类比 🎭：十一维像体检全项，日常只需按风险挑几项做专项，不必每次做全套 🏥。

## P08 · 核心指标：成功率 + 轨迹质量

> 卡片职责：落到核心分，给可操作指标

- 落到分数上就两个核心：**任务成功率**（看干成没干成）+ **轨迹质量**（看干得正不正常）。
- 成功率公式：成功完成任务数 ÷ 总任务数，判据是真实系统状态。
- τ-Bench 还引入 **pass^k** 指标：同一任务跑 k 次要求至少一次成功，衡量可靠性。
- 两个指标要一起看：**只看成功率，可能被碰巧成功骗** 📊。

## P09 · 现实很残酷：ClawBench 实测数据

> 卡片职责：给实测数据，点醒「别信 demo」

- ClawBench 实测 8 款 Agent 处理日常在线任务，**最强 Claude 才 33.3%** 完成率。
- Qwen 3.5 是 26.1%，GLM-5 是 24.2%，而 GPT-5.4 只有 **6.5%**。
- 关键启示：**模型强 ≠ Agent 强**，GPT-5.4 的低分就是「名不副实」的例子。
- 评测体系的价值：用数据告诉你，**别盲目信演示视频的惊艳效果** ⚠️。

## P10 · 判断收尾 + 互动钩子

> 卡片职责：给判据式结论 + 唯一一句互动钩子

- 判断标准：**Agent 会不会被真实使用**——会，就值得一套评测体系；不会，别过度设计。
- 开发/采购/运维 Agent 就至少搭一层「端到端 + 过程」评测，否则总在猜效果。
- 快速验证想法可只测任务成功率一个指标，够用就够。
- 一句话收束：**评测体系不是炫技，是戳穿「看着能干」的那层纸**。
