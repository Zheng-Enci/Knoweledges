# LLM05-2026年国内AI大模型选型指南：写代码与写文本双赛道推荐 💻✍️

本文聚焦**国内大模型**，基于截至 2026 年 7 月的公开 benchmark 数据和 API 定价信息，从**写代码**和**写文本**两个核心赛道出发，筛选出可通过公开 API 或网页端直接使用的国产模型，进行系统性排名对比与性价比分析，帮助国内开发者和内容创作者做出最优选型决策。
This document focuses on **domestic LLMs**, systematically ranking and analyzing cost-effectiveness across coding and text generation tracks based on public benchmark data and API pricing as of July 2026.

> **数据截止时间**：2026 年 7 月 20 日（Benchmark 数据、API 定价均为截至该日期的最新公开信息）
> **覆盖范围**：仅限国内模型，且仅选择可通过公开 API 或网页端直接使用的模型
> **免责声明**：API 定价可能随时调整，请以各厂商官方页面为准

## 术语表 / Terminology

| 术语 / Term | 说明 / Description |
|-------------|-------------------|
| **SWE-bench Verified** | 基于真实 GitHub Issue 的软件工程修复测试，衡量模型解决真实 Bug 的能力 |
| **LiveCodeBench** | 持续更新的 LeetCode/Codeforces 竞赛编程题评测，测算法实现能力 |
| **LMArena Elo** | 基于用户匿名盲测投票的 Elo 评分体系，反映真实使用体验 |
| **AA Intelligence Index** | Artificial Analysis 发布的综合智能指数，加权多维度 benchmark |
| **SuperCLUE** | 中文权威大模型评测基准，覆盖数学推理、科学推理、代码生成等六大维度 |
| **WritingBench** | 覆盖 6 大领域、100 子领域的专业化写作评测（1-10 分制） |
| **Token** | 模型处理文本的最小单位，通常 1 中文 ≈ 1-2 Token |

### 1.2 写代码赛道选型推荐

#### 🏆 写代码综合最强：DeepSeek V4 Pro

- **推荐理由**：SWE-bench Verified **80.6%**（国产第 1、开源第 1），LiveCodeBench **93.5%**（全球第 1），MATH-500 **96.8%**（国产第 1）。Codeforces 评分 **3206** 刷新开源模型纪录。1M Token 上下文窗口，MIT 开源协议，编码能力在国内模型中断层领先，在真实 Bug 修复、算法实现、数学推理三个维度均为国产顶级。
- **可用渠道**：DeepSeek 官方 API（api.deepseek.com）、阿里云百炼、腾讯云、火山引擎；开源权重可自部署
- **参考定价**：输入 ¥3 / MTok，输出 ¥6 / MTok；缓存命中 ¥0.025 / MTok；V4 Flash 版 ¥1 / ¥2
- **适合场景**：日常开发辅助、复杂工程重构、算法竞赛刷题、Agent 编程框架搭建

#### 💰 写代码性价比最高：DeepSeek V4 Pro / V4 Flash

- **推荐理由**：以 V4 Pro ¥3/¥6 的价格提供国产最强的编码能力（SWE-bench 80.6%、LiveCodeBench 93.5%），性价比无可匹敌。V4 Flash 更是低至 ¥1/¥2，在 1M 上下文窗口场景中为当前国内 **单价最低的主力模型**。等效编码成本仅为 Kimi K2.6 的约 **1/5**、GLM-5.1 的约 **1/3**。
- **可用渠道**：DeepSeek 官方 API、阿里云百炼、腾讯云
- **参考定价**：V4 Pro ¥3/¥6，V4 Flash ¥1/¥2
- **适合场景**：预算敏感的个人开发者、高并发大批量代码生成、Agent 循环任务

#### 🌟 前端开发专长：GLM-5.1

- **推荐理由**：在 DesignArena Code Category（专注视觉前端代码生成：网站、UI 组件、游戏等）中以 **1352 Elo** 登顶全球第 1，超越 GPT-5.6 Sol 和 Claude Fable 5。SWE-bench ~75%，Agent 能力突出，在工具调用与长链执行任务中表现优异。
- **可用渠道**：智谱 AI 开放平台（open.bigmodel.cn）、GLM Coding Plan
- **参考定价**：输入 ¥6 / MTok（≤32K），输出 ¥24 / MTok
- **适合场景**：前端 UI 开发、可视化页面生成、Agent 自动化工作流

### 2.2 写文本赛道选型推荐

#### 🏆 写文本综合最强：通义千问 Qwen3.7 Max

- **推荐理由**：在多项中文写作实测中，Qwen3.7 Max 的文本自然度、中文语感和文化适配性在国产模型中公认最佳，读起来「最不像 AI 写的」。AA 智能指数 **46**（国产前列），WritingBench **7.50+**，在阿里云百炼平台下载量全球第一，全球前十的开源模型全部基于 Qwen 二次开发。中文营销文案、企业公文、产品说明等场景表现均为顶级。
- **可用渠道**：阿里云百炼平台 API、通义千问网页端 / App
- **参考定价**：输入 ¥2.5 / MTok（≤32K），输出 ¥10 / MTok；新用户百万 Token 免费额度
- **适合场景**：中文营销文案、公众号/小红书创作、企业公文、产品说明书

#### 💰 写文本性价比最高：DeepSeek V4 Pro

- **推荐理由**：WritingBench **7.70**（开源模型最优），在学术写作、技术文档、逻辑性长文方面能力突出，1M 上下文窗口可覆盖整本中篇小说的批量处理。API 定价仅 ¥3/¥6，是通义千问 Qwen3.7 Max 的约 **60%**、Kimi K2.6 的约 **1/3**。对于技术文档、数据报告、学术论文等对逻辑严谨性要求高的写作场景，DeepSeek V4 Pro 在性能与价格的平衡上无可匹敌。
- **可用渠道**：DeepSeek 官方 API、阿里云百炼、腾讯云；DeepSeek 网页端
- **参考定价**：V4 Pro ¥3/¥6，V4 Flash ¥1/¥2
- **适合场景**：批量文本生成、技术文档翻译、数据报告编写、预算有限的内容团队

#### 🌟 中文创意写作首选：文心 5.1

- **推荐理由**：LMArena 文本榜 **1,476 Elo**（国产第 1），在创意写作、高难度指令遵循方面表现突出，超越 GPT-5.5。文心 5.1 采用「多维弹性预训练」技术，仅以业界同规模模型约 6% 的预训练成本达到领先效果。内置可溯源公文写作能力，事实准确率超 99%，在政府公文、企业制度文件等对准确性要求极高的场景中独具优势。
- **可用渠道**：百度千帆模型广场 API（邀测中）、文心一言网页端 / App
- **参考定价**：输入约 ¥4 / MTok，输出约 ¥8 / MTok
- **适合场景**：创意文学创作、政企公文写作、品牌故事撰写
