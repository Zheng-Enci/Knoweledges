# LLM14-2026年国内AI大模型性价比排行榜：纯语言与多模态双榜单

本文基于 SuperCLUE 2026年7月中文通用榜（纯语言）与 MMMU/OCRBench 等视觉 benchmark（多模态），结合各厂商公开 API 定价，按「benchmark 综合得分 ÷ 3:1 加权综合成本」计算性价比。筛选可通过公开 API 或网页端直接使用的国内模型，排除完全免费模型。

绝大多数场景（写代码、写文本、对话）只需纯语言模型，纯语言通常更便宜；仅当需要图片输入时才选用多模态（language + vision）模型。

> **数据截止时间**：纯语言榜 SuperCLUE 评测发布于 2026.8.6（7月榜）；多模态榜视觉 benchmark 数据截至 2026.6；API 定价取自各平台 2026年8月官方公示。
> **DeepSeek 调价提示**：DeepSeek-V4 系列自 2026.8.17 00:00 起改为峰谷定价，本文纯语言榜一律按**高峰时段**价格计算性价比（Flash 输入3/输出9、Pro 输入9/输出27 元/百万 Token）。空闲时段价格为高峰一半。
> **综合成本计算**：3:1 加权（输入价 × 0.75 + 输出价 × 0.25），单位 RMB/百万 Token
> **免责声明**：API 定价可能随时调整，请以各厂商官方页面为准
