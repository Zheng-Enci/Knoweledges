# LLM17-2026年国内AI大模型性价比排行榜：指定模型双榜单（听话视角）

本文基于 SuperCLUE 2026年7月中文通用榜（纯语言）与 MMMU / MMMU-Pro 等视觉 benchmark（多模态），结合阿里云百炼、DeepSeek、智谱官方 API 定价，按「benchmark 综合得分 ÷ 3:1 加权综合成本」计算性价比。筛选用户指定清单中的国内付费模型，排除图片生成、视频生成、语音合成/识别类生成模型（不具备通用文本/视觉理解基准可比性）。所有入选模型均满足「听话（遵循 rules 文件）」入选门槛。

在 AI IDE / Agent 场景下，模型是与人协作的 collaborator，而非孤立的 benchmark 冠军。「聪明但独断专行」的模型会破坏 workflow，因此本榜单将「项目级 rules 遵循能力」作为独立展示维度（不强行折算进性价比公式，缺乏统一公开 benchmark，避免编造）。

> **数据截止时间**：纯语言榜 SuperCLUE 评测发布于 2026.8.6（7月榜）；多模态榜视觉 benchmark 数据截至 2026.8（MMMU-Pro SOTA 截至 2026.8）；API 定价取自各平台 2026年8月官方公示。
> **限时折扣说明**：Qwen3.8-Max、Qwen3.7-Max 标注「限时夜间5折」，Qwen3.7-Plus 标注「限时8折」（阿里云百炼 Token Plan 活动），本文性价比同时列出原价与活动价口径，排名按活动价计算。
> **DeepSeek 调价提示**：DeepSeek-V4 系列自 2026.8.17 起改为峰谷定价，本文纯语言榜一律按**高峰时段**价格计算性价比（Flash 输入3/输出9、Pro 0813 输入9/输出27、Pro 输入9/输出27 元/百万 Token）。空闲时段价格为高峰一半。
> **综合成本计算**：3:1 加权（输入价 × 0.75 + 输出价 × 0.25），单位 RMB/百万 Token。
> **Rules 遵循说明**：CLAUDE.md / `.trae/rules`（AGENTS.md）/ `.cursor/rules` 等机制均为文本规则文件，模型遵从度受规则长度、上下文压缩影响；实测遵从度标注为高/中/低，源自开发者社区实测与工具官方兼容说明，非统一量化 benchmark。
> **生成类模型排除说明**：qwen-image-3.0-pro、wan2.7-image/pro、happyhorse-1.1 系列（i2v/t2v/r2v）为图片/视频生成模型，qwen-audio-3.0 系列（asr/tts/realtime）为语音识别/合成/对话模型，均不具备通用文本理解或视觉理解 benchmark 可比口径，本榜单不做性价比排名，仅在下文「排除清单」说明。
> **免责声明**：API 定价可能随时调整，请以各厂商官方页面为准。

## 总结

纯语言场景性价比最高模型：Qwen3.7-Plus — 限时8折后综合成本仅 2.80 元/百万 Token，256K 上下文，benchlm.ai 综合评分 66.0/100，支持 `.trae/rules`/`CLAUDE.md` 规则兼容，适合绝大多数写代码、写文本、对话场景；若偏好开源部署与同等低成本，可改用 Qwen3.6-Flash（综合成本 2.70 元，= Qwen3.6-35B-A3B 开源 MoE）。

多模态场景性价比最高模型：Qwen3.6-Flash — 综合成本仅 2.70 元/百万 Token，MMMU 77.0，开源可本地部署，原生图文理解，仅在确需图片输入时选用；若偏好更高视觉精度且接受略高成本，可改用 Qwen3.7-Plus（MMMU-Pro 79.0，综合成本 2.80 元）。
