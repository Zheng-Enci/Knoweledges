# LLM20-2026年9月国内大模型排行：语言最强·语言性价比·多模态最强

本文对**阿里云百炼 Standard 套餐**内的模型做三个独立榜单：语言最强、语言最具性价比、多模态最强。模型范围取自 `通用资料/阿里云百炼-Standard套餐.md`（2026年09月18日读取），API 定价取自 `通用资料/阿里云百炼-模型调用计费.md`（2026年09月18日读取）。语言榜采用文本类 benchmark（SuperCLUE 中文通用榜、GPQA Diamond、IFBench、SWE-bench），多模态榜采用视觉类 benchmark（MMMU-Pro、Vision2Web、MathVision、LVBench），两者不可跨榜直接比较。

> **本版本相对 LLM19 的两处升级**：① 榜单②引入**速度系数**，排名依据由「得分 ÷ 综合成本」改为「得分 ÷ 综合成本 × 速度系数」；② `deepseek-v4-pro`、`deepseek-v4-flash-0731` 在计费文件中无条目，按 command 新增的「缺失处理」条款**联网补价**，其性价比不再置空。

在 AI IDE / Agent 场景下，模型是与人协作的 collaborator，而非孤立的 benchmark 冠军。「聪明但独断专行」的模型会破坏 workflow，因此本榜单将「项目级 rules 遵循能力」列为独立展示维度，**不折算进性价比公式**（缺乏统一公开 benchmark，强行折算易编造数据），但**参与「最强模型」的相近得分判定**——差距 < 2 分时，以 Rules 遵循度更高者为最强。

> **数据截止时间**：语言榜 SuperCLUE 通用榜含 2026.9.10 / 2026.9.11 补测数据；速度数据截至 2026-09-11（Artificial Analysis / BenchLM 实测榜）；多模态榜视觉 benchmark 截至 2026.8—2026.9.02 快照。API 定价以本地计费文件 2026年09月18日 读取时刻为准。
> **综合成本计算**：3:1 加权（输入价 × 0.75 + 输出价 × 0.25），单位 RMB/百万 Token。
> **速度系数计算**：`速度系数 = 该模型实测 output tokens/s ÷ 榜内最快（201 tokens/s）`，归一至 0~1；**测不到实测值的模型以榜内中位 69 tokens/s 代入**并在表内标注。
> **Rules 遵循说明**：CLAUDE.md / AGENTS.md / `.trae/rules` / `.cursorrules` 本质是**文本规则文件**，无工具调用层面的强制力。受控实验（1,650 session、16,050 观测）显示规则文件长度、指令位置、文件架构均无显著效应（ICR 60.0%–67.7%，p > 0.16），真正的衰减来自**会话内合规衰减**（每多生成一个函数，合规 odds 下降约 5.6%，OR = 0.944）；OctoBench（ACL 2026）显示冲突时多数模型优先听用户 Query 而非文档规则（66%–96%）。因此本列标注「高 / 中 / 低」+ 机制说明，**非统一量化 benchmark**。
> **免责声明**：API 定价可能随时调整，请以各厂商官方页面为准。

### 各模型详情

**① Qwen3.8-Max — 语言最强（并含视觉）**

### 本章小结

「最强」判定为 **Qwen3.8-Max**：SuperCLUE 72.62 为套餐内最高，与次席 DeepSeek V4.1-Flash（71.81）分差 0.81 分（< 2 分）触发 Rules 判定——Qwen3.8-Max 依托 Qwen Code 的 `QWEN.md` + `AGENTS.md` 双默认名组合与 `@path` 导入机制，规则发现链路比 DeepSeek（仅第三方工具兼容）更完整，因此以 Rules 维度胜出。若把权重放在幻觉控制、数学推理与成本上，DeepSeek V4.1-Flash 是更务实的选择。本榜性价比列显示：**基础性价比前三（V4-Flash-0731 52.48、Qwen3.8-Flash 52.09、V4.1-Flash 41.03）与得分前三完全错位**，旗舰档全部落在个位数。

## 总结

**语言场景**：最具性价比的是 **DeepSeek V4-Flash-0731**（速度调整性价比 52.48 = 65.60 ÷ 1.25 元 × 1.00，实测 201 tokens/s 为榜内最快），适合大批量文本处理、常规问答与高频 Agent 调用；**DeepSeek V4.1-Flash**（39.60）以更接近旗舰的 71.81 分成为「得分 × 成本 × 速度」三角的平衡点最优。最强的是 **Qwen3.8-Max**（SuperCLUE 72.62，与次席 71.81 分差 0.81 < 2 分，凭 Qwen Code harness 的 `QWEN.md` + `AGENTS.md` 双默认名与 `@path` 导入机制在 Rules 维度胜出）——但它的速度调整性价比仅 0.79，是全榜最低。**引入速度系数后，Qwen3.8-Flash 因缺实测速度被按中位代入而退至第 3，这一位次由数据缺失造成，不代表其真实能力回落。**

**多模态场景**：最强的是 **Qwen3.8-Max**（MMMU-Pro 82.7，0902 快照较 8 月版 +0.4；分差 2.9 分 > 2 分阈值，直接以得分定序），在数学视觉、图表理解、长视频、视觉 Agent 四条子线上均为套餐内第一，且与语言榜冠军为同一模型——**在阿里云百炼 Standard 套餐内，它是唯一能「一个模型打全场」的选择**，代价是 18.00 元综合成本与 39.6 tokens/s 的最慢速度。预算受限的视觉任务应下沉到 **Qwen3.8-Flash**（Vision2Web 64.0 / AndroidWorld 84.5 / OSWorld 2.0 Partial 52.3，综合成本 1.275 元），纯文档解析与 OCR 场景则 **Qwen3.7-Plus**（OmniDocBench 91.4）仍有一席之地。
