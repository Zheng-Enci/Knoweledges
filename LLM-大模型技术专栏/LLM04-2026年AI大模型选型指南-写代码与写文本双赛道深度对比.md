# LLM04-2026年AI大模型选型指南：写代码与写文本双赛道深度对比 💻✍️

本文基于截至 2026 年 7 月的公开 benchmark 数据和 API 定价信息，从**写代码**和**写文本**两个核心赛道出发，对国内外主流 AI 大模型进行系统性排名对比与性价比分析，帮助开发者和内容创作者根据场景做出最优选型决策。
This document provides a systematic ranking and value analysis of mainstream AI large language models across two core tracks — **coding** and **text generation** — based on public benchmark data and API pricing as of July 2026, helping developers and content creators make optimal selection decisions for their specific scenarios.

> **数据截止时间**：2026 年 7 月 19 日（Benchmark 数据、API 定价均为截至该日期的最新公开信息）
> **免责声明**：API 定价可能随时调整，请以各厂商官方页面为准

## 术语表 / Terminology

| 术语 / Term | 说明 / Description |
|-------------|-------------------|
| **SWE-bench Verified** | 基于真实 GitHub Issue 的软件工程修复测试，衡量模型解决真实 Bug 的能力 |
| **LiveCodeBench** | 持续更新的 LeetCode/Codeforces 竞赛编程题评测，测算法实现能力 |
| **MMLU-Pro** | 大规模多任务语言理解增强版，衡量广泛学科知识掌握度 |
| **GPQA Diamond** | 研究生级别的科学推理测试（198 题专家版） |
| **LMArena Elo** | 基于用户匿名盲测投票的 Elo 评分体系，反映真实使用体验 |
| **AA Intelligence Index** | Artificial Analysis 发布的综合智能指数，加权多维度 benchmark |
| **Token** | 模型处理文本的最小单位，通常 1 中文 ≈ 1-2 Token，1 英文单词 ≈ 1-2 Token |

### 1.2 写代码赛道选型推荐

基于上述 benchmark 数据和 API 定价，给出以下推荐：

#### 🏆 写代码综合最强：Claude Fable 5

- **推荐理由**：BenchLM 编码评分 80.5（全球第 2），SWE-bench Verified 95.0%（全球第 1），LMArena Coding Elo 1563（全球第 1），在真实仓库修复、算法实现、Agent 编程三方面均为顶级表现。Anthropic 的低幻觉特性使其在复杂工程任务中更可靠。
- **可用渠道**：Anthropic 官方 API、Claude Code、Cursor 等 IDE 插件
- **参考定价**：输入 $10 / MTok，输出 $50 / MTok
- **适合场景**：大型工程代码重构、复杂 Agent 框架搭建、关键业务代码审查

#### 💰 写代码性价比最高：DeepSeek V4 Pro

- **推荐理由**：LiveCodeBench 93.5%（全球第 1），SWE-bench Verified 80.6%（开源第 1），Codeforces 评分 3206 刷新纪录 —— 编码能力稳居开源榜首。API 定价仅 ¥3 / ¥6（$0.435 / $0.87），是 Claude Fable 5 的约 **1/55**。MIT 开源协议可自部署，1M 上下文窗口全覆盖。
- **可用渠道**：DeepSeek 官方 API、阿里云百炼、腾讯云、火山引擎；开源权重可自部署
- **参考定价**：输入 ¥3 / MTok（$0.435），输出 ¥6 / MTok（$0.87）；V4-Flash 版 ¥1 / ¥2
- **适合场景**：日常开发辅助、批量代码生成、算法刷题、预算敏感的个人开发者 / 初创团队

#### 🌟 国产编码强推：Kimi K3

- **推荐理由**：2026 年 7 月发布的 2.8T 参数开源模型，Arena.ai Frontend Code Arena **1679 分登顶全球第 1**，超越 Claude Fable 5（1631）和 GPT-5.6 Sol（1618）。BenchLM 编码评分 78.0（全球第 4），在前端开发、3D 可视化、长程编码任务中表现突出。
- **可用渠道**：Kimi 官方 API（国内 / 国际）、网页客户端
- **参考定价**：未缓存输入 $3 / MTok（¥20），输出 $15 / MTok（¥100）；缓存命中输入仅 $0.3 / MTok
- **适合场景**：前端开发、全栈工程、长链路 Agent 任务

### 2.2 写文本赛道选型推荐

#### 🏆 写文本综合最强：Claude Fable 5

- **推荐理由**：LMArena 文本生成 Elo 1,509（全球第 1），AA 智能指数 60（全球第 1），在 MMLU-Pro（91.5%）、SWE-bench Verified（95.0%）、Humanity's Last Exam 等多个权威 benchmark 同时登顶。Anthropic 模型以低幻觉率（28.1%，远低于 GPT-5.5 的 42.3%）和逻辑严谨性著称，在长文写作、技术文档、法律/学术文本等要求精确性的场景中表现尤为突出。
- **可用渠道**：Anthropic 官方 API、Claude 网页端 / 移动端
- **参考定价**：输入 $10 / MTok，输出 $50 / MTok
- **适合场景**：专业级内容创作、技术白皮书、学术论文、法律合同起草

#### 🌟 中文文本写作首选：通义千问 Qwen3.7 Max

- **推荐理由**：在中文写作场景中，Qwen3.7 Max 的文本自然度、中文语感和文化适配性明显优于海外模型。WritingBench 中 Qwen 系列的中文写作评分领先，且阿里在 Hugging Face 开源模型下载量全球第 1。AA 智能指数 46（国产第 2），Terminal-Bench 终端操作得分 69.7 接近国际顶尖水平。
- **可用渠道**：阿里云百炼平台 API、通义千问网页端 / App
- **参考定价**：输入 ¥2.5 / MTok，输出 ¥10 / MTok；新用户百万 Token 免费额度
- **适合场景**：中文营销文案、公众号/小红书创作、企业公文、产品说明

#### 💰 写文本性价比最高：DeepSeek V4 Pro / V4 Flash

- **推荐理由**：WritingBench 中 DeepSeek R1 以 7.70 分位居开源模型第 1，说明其写作能力在同价位段没有对手。V4 Pro 定价 ¥3/¥6，V4 Flash 低至 ¥1/¥2，是海外竞品价格的 1/20-1/100。1M 上下文窗口适合处理长篇技术文档、代码注释生成、日志分析等大批量文本任务。
- **可用渠道**：DeepSeek 官方 API、阿里云百炼、腾讯云
- **参考定价**：V4 Pro ¥3/¥6，V4 Flash ¥1/¥2（均为 ¥ / MTok）
- **适合场景**：批量文本生成、技术文档翻译、数据报告编写、预算有限的内容团队
