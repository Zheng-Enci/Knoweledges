﻿# LLM15-2026年国内AI大模型性价比排行榜：纯语言与多模态双榜单（听话视角）

本文基于 SuperCLUE 2026年8月中文通用榜（纯语言）与 MMMU / OCRBench 等视觉 benchmark（多模态），结合各厂商公开 API 定价，按「benchmark 综合得分 ÷ 3:1 加权综合成本」计算性价比。筛选可通过公开 API 或网页端直接使用的国内模型，排除完全免费模型。所有入选模型均满足「听话（遵循 rules 文件）」入选门槛。

在 AI IDE / Agent 场景下，模型是与人协作的 collaborator，而非孤立的 benchmark 冠军。「聪明但独断专行」的模型会破坏 workflow，因此本榜单将「项目级 rules 遵循能力」作为独立展示维度（不强行折算进性价比公式，缺乏统一公开 benchmark，避免编造）。

> **数据截止时间**：纯语言榜 SuperCLUE 评测发布于 2026.8.6（7月榜）；多模态榜视觉 benchmark 数据截至 2026.8（MMMU SOTA 截至 2026.6）；API 定价取自各平台 2026年8月官方公示（火山引擎、腾讯云、阿里云百炼、llmabacus 等已于 2026.8.19–8.21 更新）。
> **DeepSeek 调价提示**：DeepSeek-V4 系列自 2026.8.17 00:00 起改为峰谷定价，本文纯语言榜一律按**高峰时段**价格计算性价比（Flash 输入3/输出9、Pro 输入9/输出27 元/百万 Token）。空闲时段价格为高峰一半。
> **综合成本计算**：3:1 加权（输入价 × 0.75 + 输出价 × 0.25），单位 RMB/百万 Token。
> **Rules 遵循说明**：CLAUDE.md / `.trae/rules`（AGENTS.md）/ `.cursor/rules` 等机制均为文本规则文件，模型遵从度受规则长度、上下文压缩影响；实测遵从度标注为高/中/低，源自开发者社区实测与工具官方兼容说明，非统一量化 benchmark。
> **免责声明**：API 定价可能随时调整，请以各厂商官方页面为准。
