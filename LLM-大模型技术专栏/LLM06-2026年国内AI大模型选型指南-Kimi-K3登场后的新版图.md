本文聚焦**国内大模型**，基于截至 2026 年 7 月的公开 benchmark 数据和 API 定价信息，从**写代码**和**写文本**两个核心赛道出发，筛选出可通过公开 API 或网页端直接使用的国产模型，进行系统性排名对比与性价比分析。相比 LLM05（截至 7/20），本文重点纳入 **Kimi K3（7/16 发布）**、**DeepSeek V4 正式版峰谷定价（7 月中旬）**、**GLM-5.2（6/17 发布）** 等最新动态，反映国内大模型竞争格局的最新变化。

## 术语表 / Terminology

| 术语 / Term | 说明 / Description |
|-------------|-------------------|
| **SWE-bench Verified** | 基于真实 GitHub Issue 的软件工程修复测试，衡量模型解决真实 Bug 的能力 |
| **SWE-bench Pro** | SWE-bench 的硬化版本，测试完整 Agent 循环（克隆仓库→定位文件→跨模块修改→运行测试→迭代修复） |
| **Frontend Code Arena** | 百万用户匿名盲测的前端开发榜单，评估网站/UI/游戏等视觉前端代码生成能力 |
| **Program Bench** | 软件逆向工程评测，衡量模型理解与还原二进制程序逻辑的能力 |
| **SWE Marathon** | 超长会话编程评测（最长 10 小时），测试模型在持续开发中的稳定性 |
| **LMArena Elo** | 基于用户匿名盲测投票的 Elo 评分体系，反映真实使用体验 |
| **AA Intelligence Index** | Artificial Analysis 发布的综合智能指数，加权多维度 benchmark |
| **SuperCLUE** | 中文权威大模型评测基准，覆盖数学推理、科学推理、代码生成等六大维度 |
| **WritingBench** | 覆盖 6 大领域、100 子领域的专业化写作评测（1-10 分制） |
| **Token** | 模型处理文本的最小单位，通常 1 中文 ≈ 1-2 Token |

### 1.2 写代码赛道选型推荐

#### 写代码综合最强：Kimi K3

- **推荐理由**：Frontend Code Arena **1679 分全球第 1**（首次有国产模型在权威编程榜登顶），Program Bench **77.8 全球第 1**，SWE Marathon **42.0 全球第 1**，LMArena Coding Arena **1529 国产第 1**。2.8 万亿参数（全球最大开源模型），1M Token 上下文，原生视觉理解。7 大前端细分领域包揽 6 项第一，两两对战胜率 76%。虽然整体性能仍落后 Claude Fable 5 和 GPT-5.6 Sol，但在编程专项上已实现多点超越。7 月 27 日开源权重。
- **可用渠道**：Kimi 官方 API（platform.kimi.ai）、Kimi Code、Kimi 网页端 / App
- **参考定价**：输入 ¥20 / MTok（缓存未命中），缓存命中 ¥2 / MTok，输出 ¥100 / MTok。约为 Claude Fable 5 的 30%
- **适合场景**：前端全栈开发、长周期工程项目、Agent 编程工作流、GPU 内核优化

#### 写代码性价比最高：DeepSeek V4 Pro

- **推荐理由**：SWE-bench Verified **80.6%**，LiveCodeBench **93.5%**，编码能力接近 GPT-5.6 Sol。平峰时段输出仅 ¥6 / MTok，Flash 版更低至 ¥2 / MTok。缓存命中输入 ¥0.025 / MTok（几乎免费）。等效编码成本仅为 Kimi K3 的约 **1/6**、GLM-5.2 的约 **1/3**。1M 上下文窗口，Agent 工具调用能力经 7/2 刷新后显著提升。支持峰谷计价——将批量任务放在平峰时段（夜间/周末）可进一步降低成本。
- **可用渠道**：DeepSeek 官方 API（api.deepseek.com）、阿里云百炼、腾讯云
- **参考定价**：V4 Pro 平峰 ¥3/¥6，高峰 ¥6/¥12；V4 Flash 平峰 ¥1/¥2，高峰 ¥2/¥4
- **适合场景**：日常开发辅助、预算敏感的个人开发者、高并发批量代码生成、Agent 循环任务

#### 开源工程编码最强者：GLM-5.2

- **推荐理由**：SWE-bench Pro **68.5%**（开源模型历史首次超越 GPT-5 和 Claude Opus 4.6），AA 智能指数 **51**（开源第 1），Code Arena 全球第 2（1595 分）。FrontierSWE **74.4%** 超越 GPT-5.5。744B 总参数 / 40B 激活参数，MIT 协议完全开源可商用。1M 上下文，IndexShare 架构将长上下文推理成本降至 2.9 倍。在长程工程任务中表现尤为突出，适合需要完整项目级理解与重构的场景。
- **可用渠道**：智谱 AI 开放平台（open.bigmodel.cn）、GLM Coding Plan
- **参考定价**：输入 ¥8 / MTok，输出 ¥28 / MTok；缓存命中 ¥2 / MTok。Coding Plan Lite ¥49/月
- **适合场景**：企业级代码 Agent、大型项目重构、后端系统工程、需要 MIT 商用授权的自部署场景

### 2.2 写文本赛道选型推荐

#### 写文本综合最强：通义千问 Qwen3.7 Max

- **推荐理由**：在多项中文写作实测中，Qwen3.7 Max 的文本自然度、中文语感和文化适配性在国产模型中公认最佳，读起来「最不像 AI 写的」。AA 智能指数 **46**（国产前列），WritingBench **7.50+**。Hugging Face 上 Qwen 系列衍生模型超 20 万个，下载量全球第一。**网页端/App 个人版永久免费**，无次数限制，对个人用户是零成本的最强中文写作工具。在阿里云百炼平台下载量全球第一，全球前十的开源模型全部基于 Qwen 二次开发。
- **可用渠道**：阿里云百炼平台 API、通义千问网页端 / App（个人免费）
- **参考定价**：API 输入 ¥12 / MTok，输出 ¥36 / MTok；网页端/App 个人版永久免费
- **适合场景**：中文营销文案、公众号/小红书创作、企业公文、产品说明书

#### 写文本性价比最高：DeepSeek V4 Pro

- **推荐理由**：WritingBench **7.70**（开源模型最优），在学术写作、技术文档、逻辑性长文方面能力突出，1M 上下文窗口可覆盖整本中篇小说的批量处理。平峰时 API 定价仅 ¥3/¥6，是 Qwen3.7 Max 的约 **25%/17%**、Kimi K3 的约 **15%/6%**。对于技术文档、数据报告、学术论文等对逻辑严谨性要求高的写作场景，DeepSeek V4 Pro 在性能与价格的平衡上无可匹敌。搭配峰谷计价，将批量任务放在平峰时段可进一步压缩成本。
- **可用渠道**：DeepSeek 官方 API、阿里云百炼、腾讯云；DeepSeek 网页端
- **参考定价**：V4 Pro 平峰 ¥3/¥6，高峰 ¥6/¥12；V4 Flash 平峰 ¥1/¥2
- **适合场景**：批量文本生成、技术文档翻译、数据报告编写、预算有限的内容团队
