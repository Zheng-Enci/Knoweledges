## P01 · 封面

> 卡片职责：抛钩子，标题 + 核心痛点

- 大标题：**agent 凭什么自己变聪明？**
- 副标题：训练完就静止，全靠这**三台引擎**
- 痛点：为什么你的 agent **越用越笨**？

## P02 · 静止困境

> 卡片职责：讲「训练后静止」这个根本问题

- LLM 权重在预训练后就**冻结**了
- agent 像一个**失忆的执行者**
- 这次成功，下次同类任务**依旧从零开始**
- 越用越差，不是模型笨，是**留不住经验**

## P03 · 本体内核

> 卡片职责：讲核心转变——改参数 vs 攒经验

- 传统优化**参数**，自进化优化**经验**
- 「执行 → 反思 → 固化 → 检索」闭环
- 四组件：**执行器/反思器/经验库/检索器**
- 比喻：随身带**笔记本的实习生**

## P04 · 引擎一：反思

> 卡片职责：讲第一引擎「反思机制」

- 鼻祖 **Reflexion**：用语言反馈强化 agent
- 失败后写一句**批评**，存进记忆，下轮复用
- 解决**信用分配**：把笼统失败拆成具体归因
- 效果：HumanEval 从 **80% 提到 91%**，零微调

## P05 · 引擎二：记忆

> 卡片职责：讲第二引擎「经验记忆」

- 关键不是存得多，是**存得对、取得准**
- **SAGE**：用遗忘曲线管理记忆，防冗余
- **ReasoningBank**：只沉淀可泛化的推理策略
- 实测：最多 **20% 相对提升**，还少走 **16% 弯路**

## P06 · 引擎三：技能

> 卡片职责：讲第三引擎「技能进化」

- 不只是避坑，是要**长出可复用技能**
- **EvolveR**：在线交互 → 离线蒸馏 → 原则库
- **hermes-agent**：失败→反思→自动生成 Skill
- 三种深度：**记教训 → 练技能 → 长本事**

## P07 · 证据说话

> 卡片职责：讲论文实测数据

- **FLEX**：AIME25 从 40% 提到 **63.3%**
- 只靠 **49 个示例**，相对提升 **58.7%**
- 不重训权重，纯靠经验/反思/记忆
- **经验自身也有缩放定律**：先广后精

## P08 · 经验缩放

> 卡片职责：讲「经验缩放定律」这个反直觉点

- 经验增长是**对数型曲线**
- epoch1→2 猛增 **+576 条**，epoch4→5 只 +64 条
- 早期覆盖问题空间，后期**选择性精炼**
- 甚至能**跨 agent 继承**，新 agent 不必从零交互

## P09 · 对照代码

> 卡片职责：给一段可直接跑的对照 demo

- 静态 agent：**每次重来**
- 自进化 agent：**失败→反思→存经验→复用**
- 核心是 `_retrieve` + `_reflect_and_store`
- 真实场景换成向量数据库 + LLM 反思即可

## P10 · 结局

> 卡片职责：末页给判据式结论

- **「重复 + 长期」**才值得上自进化
- 「一次性 + 高风险」先别碰
- 先补经验机制，再考虑重训模型
- 你的 agent 是**天才**还是**实习生抽卡**？
