# LLM08-2026年国内AI大模型性价比与价格排行榜

本文基于 SuperCLUE 2026年6月中文大模型排行榜和各大厂商公开 API 定价，按「benchmark 综合得分 ÷ 3:1 加权综合成本」计算性价比，筛选可通过公开 API 或网页端直接使用的模型，排除完全免费模型。

> **数据截止时间**：2026 年 7 月 23 日（Benchmark 数据、API 定价均为截至该日期的最新公开信息）
> **综合成本计算**：3:1 加权（输入价 × 0.75 + 输出价 × 0.25），单位 RMB/百万 Token
> **免责声明**：API 定价可能随时调整，请以各厂商官方页面为准

### 各模型详情

**① DeepSeek V4-Flash — 极致性价比之王**

- **推荐理由**：2840 亿参数 MoE 架构，输入 1 元/百万 Token、输出 2 元/百万 Token，综合成本仅 1.25 元。SWE-bench 代码能力接近 V4-Pro 水平，适合轻量级生产场景和高并发调用。
- **可用渠道**：DeepSeek API（OpenAI 兼容）、网页端 chat.deepseek.com
- **参考定价**：输入 1 元，输出 2 元（综合成本 1.25 元）

**② 讯飞星火 X2-Flash — 轻量 Agent 性价比之选**

- **推荐理由**：30B 参数 MoE 架构，256K 超长上下文，基于华为昇腾 910B 国产算力。Agent 任务效果接近万亿级模型，成本仅主流大尺寸模型的 1/3。2026 年 6 月推出「无限 Token」活动。
- **可用渠道**：讯飞开放平台 API、星辰 MaaS 平台
- **参考定价**：输入 1 元，输出 2 元（综合成本 1.25 元）

**③ 腾讯混元 Hy3 — Agent 性价比黑马**

- **推荐理由**：295B 总参数/21B 激活 MoE 架构，SWE-bench Verified 78.0，GPQA Diamond 90.4。内部 Agent 任务完成率 90%，270 位专家盲测均分 2.67/4。办公场景 Token 消耗比 GLM-5.2 低 47-49%。Apache 2.0 开源。
- **可用渠道**：腾讯云 API、元宝 App、WorkBuddy
- **参考定价**：输入 1 元，输出 4 元，缓存命中 0.25 元（综合成本 1.75 元）

**④ Qwen3.5-Plus — 中文写作性价比首选**

- **推荐理由**：SuperCLUE 6 月 88.5 分领跑国产，中文写作本土化表达断层领先。阿里生态（钉钉、淘宝、百炼平台）深度集成。输入 2 元/百万 Token，输出 4 元/百万 Token，性价比极高。
- **可用渠道**：阿里云百炼平台、通义千问网页端
- **参考定价**：输入 2 元，输出 4 元（综合成本 2.50 元）

**⑤ DeepSeek V4-Pro — 综合能力标杆**

- **推荐理由**：SuperCLUE 5 月总分 70.48（国产第一）、SWE-bench 80.6%（国产代码第一）、LMArena Elo 1,467（国产最高）。1.6T 参数/49B 激活 MoE 架构，1M 上下文，MIT 开源。平时段输入 3 元/百万 Token，缓存命中仅 0.025 元。
- **可用渠道**：DeepSeek API（OpenAI 兼容）、网页端 chat.deepseek.com
- **参考定价**：输入 3 元，输出 6 元（综合成本 3.75 元；缓存命中综合成本仅 0.27 元）

**⑥ MiniMax M2.7 — Agent 编程性价比之选**

- **推荐理由**：230B 参数 MoE 架构，SWE-Pro 56.2%，Terminal Bench 2 得分 57.0%。Agent 场景深度优化，工具调用和复杂任务规划能力强。开源可商用，输入 2.1 元/百万 Token。
- **可用渠道**：MiniMax API、阿里云百炼等第三方平台
- **参考定价**：输入 2.1 元，输出 8.4 元（综合成本 3.68 元）

**⑦ Doubao-Seed-2.0-pro — 多模态能力标杆**

- **推荐理由**：SuperCLUE 6 月 87.8 分排名第二，LMArena 视觉理解维度全球第 4。多模态能力全面领先，Codeforces Elo 3,020。345M MAU 中国最大 AI 助手。
- **可用渠道**：火山引擎 API、豆包 App
- **参考定价**：输入 $0.47/百万 Token（≈3.3 元），输出 $2.37（≈16.5 元），综合成本约 6.60 元

**⑧ Kimi K2.6 — 长文本与代码编程利器**

- **推荐理由**：SWE-bench Verified 80.2%，国产代码能力第二。百万级上下文无损解析，长文本处理无可替代。1T 参数 MoE 架构，开源 Apache 2.0。
- **可用渠道**：Kimi API、Web/App 端
- **参考定价**：输入 6.5 元，输出 27 元（综合成本 11.63 元）

**⑨ GLM-5.1 — 代码 Agent 开源 SOTA**

- **推荐理由**：SuperCLUE 6 月 85.4 分排名第四，Agent 工具链成熟度国产最高（MCP 协议原生支持、多 Agent 协作框架）。MIT 开源。

- **可用渠道**：百度智能云 API、文心一言网页端
- **参考定价**：输入 16.57 元，输出 16.57 元（综合成本 16.57 元；另有 Lite 版仅 0.41/0.83 元）
