# 2026 年国内 AI 大模型性价比排行榜

> 基于截至 2026 年 8 月 15 日的公开数据，对可通过公开 API 或网页端直接调用的国内大模型进行性价比排名。benchmark（基准测试）综合得分采用 SuperCLUE 智能指数（满分 100 分，2026 年 7 月测评），综合成本按 **输入:输出 = 3:1 加权**，即 综合成本 = 输入价 × 0.75 + 输出价 × 0.25（单位：元 / 百万 tokens）。已排除完全免费调用的模型。

**数据说明**

| 项目 | 说明 |
|---|---|
| 数据截止时间 | 2026-08-15 |
| 覆盖范围 | 国内模型，仅限公开 API 或网页端可用 |
| 排除标准 | 完全免费调用模型（如 GLM-4.7-Flash、Kimi K2.7 Code Free 等免费档） |
| 计算方法 | 性价比指数 = benchmark 综合得分 ÷ 综合成本；综合成本 = 输入价 × 0.75 + 输出价 × 0.25 |
| 免责声明 | API 定价随时调整，请以各厂商官方页面为准 |

## 2. 各模型详细推荐（Recommendations）

### 2.1 DeepSeek V4 Flash（深度求索）— 性价比之王

- **推荐理由**：SuperCLUE 智能指数 **65.60**，数学推理 **78.95** 为 7 月榜单全场最高；AA（Artificial Analysis，全球评测机构）智能指数 52，全球前 20；1M 超长上下文。以全榜最低价实现第一梯队推理能力。
- **可用渠道**：DeepSeek 开放平台 API（模型 ID `deepseek-v4-flash`）、阿里云百炼、火山引擎方舟；网页端 chat.deepseek.com
- **参考定价**：输入 ¥1.0 / 输出 ¥2.0（缓存命中 ¥0.2）→ 综合成本 ¥1.25
- ⚠️ 火山引擎公告：2026-08-21 起价格上调至 输入 ¥3.0 / 输出 ¥9.0，当前为低价窗口

### 2.2 混元 Hy3（腾讯）— 低价高能黑马

- **推荐理由**：SuperCLUE **62.13**，科学推理 **75.44** 国产前列；开源可自部署，腾讯生态（元宝、腾讯云）深度集成。
- **可用渠道**：腾讯云混元大模型 API；网页端腾讯元宝
- **参考定价**：输入 ¥1.2 / 输出 ¥4.0（最低档）→ 综合成本 ¥1.90

### 2.3 DeepSeek V3.2（深度求索）— 稳健低价常青款

- **推荐理由**：SuperCLUE 2025 年 11 月测评 **53.69**（当时开源第一）；官方宣称推理能力对标 GPT-5；128K 上下文，首个将思考融入工具调用的 DeepSeek 版本。
- **可用渠道**：DeepSeek 开放平台 API（模型 ID `deepseek-v3.2`）、阿里云百炼；网页端 chat.deepseek.com
- **参考定价**：输入 ¥2.0 / 输出 ¥3.0 → 综合成本 ¥2.25

### 2.4 DeepSeek V4 Pro（深度求索）— 旗舰性能的性价比之选

- **推荐理由**：SuperCLUE **64.40**，精确指令遵循 **49.52** 为 7 月榜单国产最高；1M 超长上下文；价格约为 V4 Flash 的 3 倍但能力更强。
- **可用渠道**：DeepSeek 开放平台 API（模型 ID `deepseek-v4-pro`）、火山引擎方舟；网页端 chat.deepseek.com
- **参考定价**：输入 ¥3.0 / 输出 ¥6.0（缓存命中 ¥0.025）→ 综合成本 ¥3.75

### 2.5 MiniMax M3（稀宇科技）— 五折促销的多模态开源旗舰

- **推荐理由**：SuperCLUE **56.90**；SWE-Bench Pro（真实仓库软件工程评测）**59.0%**，超越 GPT-5.5 与 Gemini 3.1 Pro；原生多模态（文本/图像/视频输入）+ 1M 上下文。
- **可用渠道**：MiniMax 开放平台 API（模型 ID `MiniMax-M3`）、腾讯云 TokenHub；网页端 minimax.io
- **参考定价**：输入 ¥2.1 / 输出 ¥8.4（限时五折，原价 ¥4.2 / ¥16.8）→ 综合成本 ¥3.68

### 2.6 ERNIE 5.1（百度文心）— 低价闭源旗舰

- **推荐理由**：SuperCLUE **54.56**，幻觉控制 **83.02** 位列榜单前列；LMArena 搜索榜国内第一；依托百度搜索生态，检索增强场景优势明显。
- **可用渠道**：百度千帆 Qianfan API（模型 ID `ernie-5.1`）；网页端文心一言
- **参考定价**：输入 ¥4.0 / 输出 ¥18.0（≤32K 档）→ 综合成本 ¥7.50

### 2.7 Doubao Seed 2.1 Pro（字节跳动）— 科学推理最强闭源

- **推荐理由**：SuperCLUE **65.94**，科学推理 **77.19** 为 7 月榜单国产最高；深度集成 TRAE、Cursor 等编程工具链，256K 上下文。
- **可用渠道**：火山引擎方舟 API（模型 ID `doubao-seed-2-1-pro`）；豆包网页端 / TRAE
- **参考定价**：输入 ¥6.0 / 输出 ¥30.0（缓存命中 ¥1.2）→ 综合成本 ¥12.00

### 2.8 GLM-5.2（智谱 AI）— 1M 上下文编程旗舰

- **推荐理由**：SuperCLUE **63.27**；AA 智能指数 53（发布时开源最高）；CodeArena 代码盲测 Elo **1595**（全球第二、开源第一）；Terminal-Bench 2.1 **81.0**（首个破 80 分的开源模型）；1M 上下文。
- **可用渠道**：智谱开放平台 API（模型 ID `glm-5.2`）、阿里云百炼；网页端智谱清言
- **参考定价**：输入 ¥8.0 / 输出 ¥28.0（<32K 档 ¥6 / ¥24）→ 综合成本 ¥13.00

### 2.9 Qwen3.8-Max（阿里巴巴）— 国产综合能力第一

- **推荐理由**：SuperCLUE **71.48** 国产第一，智能体任务规划 **90.94** 断层领先；AA 智能指数 58（全球第 9）；LMArena 文本榜 Elo **1497**（全球第 6）；2.4T 参数 MoE、1M 上下文。
- **可用渠道**：千问 AI 平台 / 阿里云百炼 API（模型 ID `qwen3.8-max`）；网页端通义千问
- **参考定价**：输入 ¥12.0 / 输出 ¥36.0（缓存命中 ¥1.5）→ 综合成本 ¥18.00

### 2.10 Kimi K3（月之暗面）— 能力顶尖但价格最贵

- **推荐理由**：SuperCLUE **70.68**；AA 智能指数 **60**（全球第 6）；智能体编程 **75.79** 为 7 月榜单全场最高；2.8T 参数、1M 上下文（2026-07-27 开源）。
- **可用渠道**：月之暗面开放平台 API（模型 ID `kimi-k3`）；网页端 kimi.com
- **参考定价**：输入 ¥20.0（缓存命中 ¥2.0）/ 输出 ¥100.0 → 综合成本 ¥40.00
- ⚠️ 推理 token（词元）按输出价计费，实测推理占输出总量 43%–77%，实际输出成本可能显著高于标价

## 3. 总结（Summary）

```
全场景性价比最高模型：DeepSeek V4 Flash
```

> 补充结论：DeepSeek 系以「低价 + 开源 + 高性能」策略占据性价比前四中的 3 席；能力排名第一的 Qwen3.8-Max 与第二的 Kimi K3 因定价较高，性价比排名靠后，适合对单次推理质量要求极高、对成本不敏感的场景。
