## 全文摘要

本文档面向「出题配图」场景——用户写出 100-150 字的高度具体单图描述（几何图形 / 钟面 / 实物计数 / 生活情境 / 条形统计图五类），文生图模型一次性产出可直接印进试卷的小学数学教科书风格扁平矢量插图。这不是艺术创作，而是一道 **视觉指令遵循题** ：元素一个不多一个不少、数量精确、几何关系正确、纯白背景无文字水印。核心证据来自 MathGen benchmark（900 道数学可视化题 + verifier 判卷）：Nano Banana Pro 综合 42.0% 断层第一（平面几何域 74.3%），GPT Image 系 Counting 60.0% 第一——「综合画质美」和「画得对」是两种能力，选型必须逐题型验证 📊

结论先行：效果优先的推荐组合是 **GPT Image 2 (medium) 全能主力 + Nano Banana Pro 硬几何旗舰 + Seedream 5.0 Pro 国内直连备胎 + LLM 写 SVG / Matplotlib 代码兜底** ，按题型分层路由，100 张图成本约 ¥50（全旗舰方案的一半）。风格上记住扁平三件套（硬边缘 / 黑描边 / 零渐变）必须显式写进 prompt；验收时数一数苹果、量一量平行、放大找渐变。一个好消息：这批 prompt 全部要求「无文字」，恰好绕开了文生图最拉胯的文字渲染能力——最难的题已经被划掉了 😄

## 1. 场景定义：5 类插图 Prompt 解剖 🎯

### 1.1 核心需求拆解

「出题配图」场景的工作流 = 用户写一段 **100-150 字的高度具体单图描述** → 文生图模型一次性产出 **可直接印进试卷** 的插图。它不是「画得好看就行」的艺术创作，而是一道 **视觉指令遵循题** ，核心考核三件事：

1. **元素清单遵循**：prompt 点名的每个元素必须出现，没点名的一个不能多——「无其他元素」是硬约束
2. **结构与数量精确**：平行就是平行、 5 个就是 5 个、 时针必须指右——错一个就不合格
3. **风格统一**：小学教科书风格 + 扁平矢量 + 纯白背景 + 无文字无水印，全系列图混排进同一份试卷不能违和

一个好消息：这批 prompt 全部要求「无文字」，恰好绕开了文生图模型最拉胯的文字渲染能力（见第 4 章 CAGE 研究：教学插图文字标签保真率不足 19%）——相当于考试划掉了最难的大题 😄

### 1.2 五类题型的技术难点分布

| 类别 | Prompt 要点 | 核心难点 | 难度 |
|------|------------|---------|:----:|
| 几何图形（梯形） | 上底∥下底、两腰不平行、浅黄填充、黑粗边线 | 平行 / 不平行是 **关系约束** ，模型易画成一般四边形 | ⭐⭐⭐⭐⭐ |
| 钟面 | 12 刻度均匀、时针指右、分针指上、长短粗细对比 | 高密度重复元素 + 指针 **方向语义** | ⭐⭐⭐⭐ |
| 实物计数（5 苹果） | 恰好 5 个、大小一致、间距均匀、各带一叶 | **数量精确** 是文生图公认老大难 | ⭐⭐⭐⭐⭐ |
| 生活情境（公路车树太阳） | 公路在下、车头朝右、左右各一树、太阳右上 | 多元素 **位置布局** ，约束最宽松 | ⭐⭐ |
| 条形统计图 | 4 根条、高度递增、蓝绿橙红、等距、无刻度数字 | 高度 **序列推理** + 颜色顺序映射 | ⭐⭐⭐⭐ |

一个反直觉的冷知识：MathGen 论文实测发现 **钟面反而是模型相对擅长的** ——训练数据里钟面插图极多，模型「背」下来了常见画法；但让它在白纸上画一个精确角度，立刻原形毕露 🤔 这意味着选型不能只看「综合美不美」，要逐类题单独验证。

### 1.3 选型目标

| 目标维度 | 期望值 |
|---------|--------|
| 元素出现 / 不出现的遵循率 | ≥ 95% |
| 数量精确率（counting） | ≥ 90% |
| 几何关系正确率（平行 / 角度） | ≥ 90% |
| 位置与方向遵循率 | ≥ 95% |
| 风格一致性（扁平矢量 + 白底） | ≥ 95% |
| 无文字 / 无水印 | 100% |
| 单张成本 | ≤ 0.5 元（效果优先，可放宽） |
| 中文 prompt 原生支持 | 必须（prompt 用中文写的） |
| 国内 API 直连 | 强加分 |

## 2. 评估维度与指标 📐

### 2.1 数量遵循 (Counting Fidelity)

**定义**：生成图中目标物体数量与 prompt 指定数一致的比例。

文生图模型的 counting 为什么难？模型本质在「画一个大概像五样东西的排列」，靠训练时学到的 **知觉重复模式** 近似枚举，而不是真的在数数。MathGen 对 900 道数学可视化题的实测（Counting 域）：

| 模型 | Counting 准确率 | 备注 |
|------|:--------------:|------|
| GPT-Image-1.5 | **60.0%** | 枚举类第一 |
| Nano Banana Pro | 42.9% | 整体最强但枚举非第一 |
| GPT-Image-1 | 34.3% | |
| Qwen-Image | 31.4% | 开源阵营 counting 意外地不差 |
| FLUX-2-Pro | 22.9% | 开源扩散最强之一 |
| Seedream 4.0 | 22.9% | |
| SD-3.5-Large | 14.3% | |
| Z-Image-Turbo | 11.4% | |

**关键发现**：counting 是所有数学域里「最容易被近似」的——「5 个苹果横向整齐排列」这类 **规整排布** 会显著提高准确率（知觉重复好使）；「树上 5 个苹果」这种开放式排布则会崩掉。你的 prompt「横向整齐排列」恰好踩在模型舒适区 😄

### 2.2 结构与几何保真 (Structural Fidelity)

**定义**：平行、垂直、角度、对称等 **关系约束** 的正确率。这是梯形题的生死线。

MathGen Plane Geometry / Angle 域数据：

| 模型 | Plane 域 | Angle 域 | 备注 |
|------|:--------:|:--------:|------|
| Nano Banana Pro | **74.3%** | 20.0% | 平面几何断层第一 |
| GPT-Image-1 | 48.6% | 20.0% | |
| GPT-Image-1.5 | 45.7% | 17.1% | |
| FLUX-2-Pro | 31.4% | 14.3% | 开源最强 |
| Imagen 4 Ultra | 31.4% | 2.9% | |
| Seedream 4.0 | 2.9% | 8.6% | |
| Qwen-Image | 0.0% | 5.7% | |

**关键发现**：平面几何是 Nano Banana Pro 的主场；国产双雄在 **严格几何约束** 下接近团灭（Qwen Plane 0%、Seedream 2.9%）——「好看」和「画对」是两种能力 🗡️ 但注意：测试用的是严格 verifier 判卷，实际教学插图对「视觉上平行」的容忍度更高，国产模型未必像分数那么惨。

### 2.3 位置布局遵循 (Layout Adherence)

**定义**：「车头朝右」「太阳在右上角」「公路在下方」这类空间方位指令的执行准确率。目前没有权威 benchmark，依赖实测（SciFig 的 instruction adherence、Vofy 的 usability 均可作参考信号）。

### 2.4 风格控制 (Style Control)

**定义**：扁平矢量（硬边缘、黑描边、零渐变）、纯白背景、教科书风的还原度。

PixelDojo 2026-08 同 prompt 实测给出一针见血的结论： **「画得最美」和「真扁平」是反义词** ——Qwen Image 2.0 画出全场最美的图，但笔刷纹理 + 柔光渐变直接违反扁平约束；唯一硬边缘 + 黑描边 + 零渐变的是 Recraft V4.1。判定方法： **先放大看有没有渐变，再看其他一切** 。

### 2.5 约束遵循：无文字、无水印

文生图模型有「手痒写点什么」的通病，统计图（想补刻度数字）和钟面（想补数字）是重灾区。验收规则：出现任何文字 / 数字 / 水印，直接判不合格。

### 2.6 中文 Prompt 理解与成本

prompt 是中文长描述，要求对中文空间方位词（左 / 右 / 上 / 下 / 朝向）语义精确。国产模型母语优势，国际模型中文理解参差。成本横向对比见第 3 章盘点表。

## 4. 关键评测数据：数学可视化与风格实测 🔬

### 4.1 MathGen：数学可视化专项 benchmark

MathGen（arXiv 2603.27959）用 900 道数学题 + 可执行 verifier 严格判卷，是目前与本场景 **重合度最高** 的评测。综合成绩：

| 模型 | Overall | 亮点域 | 塌方域 |
|------|:-------:|--------|--------|
| **Nano Banana Pro** | **42.0%** | Plane 74.3% / Function 51.4% / Solid 40.0% | Angle 20.0% |
| GPT-Image-1.5 | 35.7% | Counting 60.0% / Solid 50.0% | Function 17.1% |
| GPT-Image-1 | 28.4% | Plane 48.6% | Fraction 之后的域普遍 <35% |
| FLUX-2-Pro | 19.1% | 开源最强 | Plane 31.4% |
| Nano Banana | 14.9% | Set 14.3% | Angle 5.7% |
| Seedream 4.0 | 12.5% | Solid 33.3% | Plane 2.9% |
| Qwen-Image | 10.8% | Counting 31.4% | **Plane 0.0%** |

三个对本场景直接有用的结论：

1. **规整场景远好于开放场景**：Clean-Scene（白底、孤立主体）下大部分模型表现尚可，放进真实语境立刻跳水。你的 prompt 全是「纯白背景 + 画面中央」，正好站在 Clean-Scene 的加分区 ✅
2. **枚举靠模式、结构靠推理**：counting 可以用知觉重复「蒙」对，但平行 / 角度需要真正的空间推理——前者重roll 可救，后者重roll 大概率还是错
3. **钟面是意外福利**：常见钟面画法在训练数据里泛滥，模型反而容易画对（时针分针位置语义也比抽象角度好使）

### 4.2 扁平矢量风格：PixelDojo 同 prompt 对决

PixelDojo（2026-08-26）用同一段扁平插画 prompt 横测三个模型，排名标准是「硬边缘、黑描边、零渐变」三大扁平铁律：

| 排名 | 模型 | 判词 |
|:----:|------|------|
| 1 | **Recraft V4.1** | 唯一「真扁平」：硬边缘 + 细黑描边 + 全画面零渐变，指定三色全部忠实还原 |
| 2 | Z-Image Turbo | 精神扁平但没画描边，整体偏软；颜色也漂移（coral → salmon） |
| 3 | Qwen Image 2.0 | **全场画得最美，但画的是水彩** ：笔刷纹理 + 柔光渐变，直接违反两条铁律 |

SVGMaker 与 OpenArt 的横向观点互为印证：GPT Image 系自带「贴纸感」（粗描边 + 平涂色块，天生好矢量化）、Seedream 4.5 擅长扁平 2D 插画、Qwen 偏「插画风」而非「扁平风」。 **结论：扁平教科书风这个特定风格上，Recraft 与 GPT Image 系的「出厂默认」最贴，国产双雄需要靠 prompt 强行压渐变** 。

### 4.3 科学 / 数据图表：GPT Image 2 的主场

- **SciFig 十学科 24 图实测**（2026-04）：GPT Image 2 的 prompt 保真度 99.2%——1500 字 prompt 里点名的元素几乎全出现；化学符号、坐标轴、公式标注稳定渲染。Nano Banana Pro 则以「留白与呼吸感」取胜（可读性 4.67 vs 4.25），但复杂拓扑会犯概念性错误（把 Möbius 环画成了普通圆柱，GPT 全对）🔪
- **Vofy 插画 + 信息图实测**（2026-08）：GPT Image 2 在「精确文字与数据」项第一—— **条形图的每一根比例都最忠实** ，正对第 5 类统计图需求；通义 Wan 2.7 两次首图全部可用（可用率 100%）是最稳的黑马。

### 4.4 路线之争：直接生图 vs 代码画图

Math-Vision Diagrams benchmark（arXiv 2608.08964）对比了「文生图」与「LLM 写代码画图」两条路线：Nano Banana 系可靠性近乎 100%（无编译失败），但结构精度（Edge IoU ≈ 0.077-0.079）不敌代码路线（Gemini 3.1 Pro 写 SVG 达 0.095）。翻译成人话： **如果某类图对几何精度要求苛刻到偏执（比如精确的统计图、函数图像），让 LLM 写 SVG/Matplotlib 代码可能比文生图更准** ——这是第 6 章 Pipeline 的备选方案来源 💡

盲测投票口径下，2026-09 榜首是 GPT Image 2.5 Flare（Elo 1188）、Sunburst（1182）、GPT Image 2 (high)（1171）；open-weights 口径下 GPT Image 2 (high) 1371 居首、Nano Banana 2 1321 在列。注意两套口径数字不可直接互比。Arena 榜衡量的是「哪张图人类更爱看」，与本场景的「指令遵循」正交——榜单第一 ≠ 5 个苹果数得对 ⚠️

## 6. 推荐方案与 Pipeline 🛠️

### 6.1 分层路由：按题型分配模型

「效果好一点」的正确姿势不是全押一个模型，而是 **按题型难度路由** ：

| 层级 | 适用题型 | 首选 | 兜底 |
|------|---------|------|------|
| 旗舰线 | 梯形等硬几何、要求高的统计图 | Nano Banana Pro（¥0.95） | GPT Image 2 (high) |
| 主力线 | 钟面、计数苹果、生活情境 | GPT Image 2 (medium，¥0.38) | Seedream 5.0 Pro（国内直连首选） |
| 经济线 | 草稿、批量预览、可接受重抽 | Seedream 5.0 Lite / Qwen-Image-3.0 | CogView-4（¥0.06 批抽） |
| 兜底线 | 严格统计图 / 几何精确 | LLM 写 SVG 或 Matplotlib 代码 | Recraft V4.1 Vector 出可编辑 SVG |

**成本测算**（100 张图）：

- 全部走 Seedream 5.0 Pro：≈¥30
- 全部走 Nano Banana Pro：≈¥95（Batch 半价 ≈¥48）
- 分层路由（20% 旗舰 + 60% 主力 + 20% 经济）：≈¥50

### 6.2 Prompt 策略：五个实测有效的技巧

1. **扁平三件套显式化**：「硬边缘、黑色描边、纯色平涂、零渐变、纯白背景」逐词写进 prompt——PixelDojo 实测这三条是模型的分水岭，漏一条就给你偷偷上光效 🎨
2. **计数规整化**：「横向整齐排列成一行，间距相等，大小一致」——MathGen 证据表明规整排布吃知觉重复 buff，开放式散布是崩坏重灾区
3. **几何关系冗余强调**：「上底与下底互相平行且长度不等；左右两腰向内倾斜、互不平行」——关系约束写两遍，正反都说（说「不平行」比只说「平行」更能压住模型的对称强迫症）
4. **否定约束放最后**：「无其他元素，无文字，无水印」收尾——长 prompt 的尾部位权重大，且这是验收硬指标
5. **国际模型配英文 prompt**：Recraft / GPT Image 用中文描述的机翻版（例如 flat vector illustration, pure white background, bold black outlines, no gradients），中文原文别直接扔给它们

### 6.3 出图与验收流程

```
中文原稿 prompt
  → [国际模型？] 机翻英文
  → 调用 API（n=4 批量抽卡，固定 seed 便于复现）
  → 自动粗筛 + 人工验收 checklist：
     □ 数一数：苹果是 5 个？条形是 4 根？
     □ 看关系：上底下底平行？两腰不平行？
     □ 看方向：时针朝右分针朝上？车头朝右？
     □ 放大 200%：有没有渐变 / 笔刷纹理？
     □ 找茬：有没有多余元素 / 文字 / 数字 / 水印？
  → 不合格 → 重roll（同模型 ≤3 次）
     → 仍不合格 → 路由到上一层模型（经济 → 主力 → 旗舰）
     → 结构性错误（平行关系错）→ 直接上代码兜底线
```

### 6.4 代码兜底线：统计图与几何图的终极解法

第 4.4 节的证据链指向一个朴素的真理： **精确的图表，代码画比 AI 画准** 。让 LLM 生成 SVG / Matplotlib 脚本：

- 优点：坐标像素级可控、样式模板一次定义全系列统一、天然零水印、可无限微调
- 缺点：画面「呆板」，缺少插画味——所以它只兜底梯形和统计图这两类「对错敏感」的图，苹果和太阳这种还是交给文生图的生动感 😄

## 7. 关键限制与避坑指南 ⚠️

### 7.1 十个高频翻车点

| # | 坑 | 现象 | 解法 |
|:-:|----|------|------|
| 1 | 迷信综合榜 | Arena Elo 第一的模型画不准 5 个苹果 | 按 5. 章 Decision Matrix 逐题型选型，美学 ≠ 指令遵循 |
| 2 | 无效重抽 | 平行关系错，同 prompt 重roll 10 次还是错 | 结构性错误重roll 无效（模型不会数数推理），直接换模型或上代码 |
| 3 | 渐变偷袭 | 放大才发现「浅黄填充」带了光影渐变 | prompt 写死「零渐变」，验收放大 200% |
| 4 | 统计图自带数字 | 模型好心给坐标轴补上刻度 | 「无刻度数字、无任何文字」显式写入 + 验收必查 |
| 5 | 钟面自带数字 | 「代替数字」的理解分歧，模型照画 12/3/6/9 | 「表盘上只有刻度线，无任何数字」双重强调 |
| 6 | 多余元素 | 白送一朵云、一只鸟、一个影子 | 「无其他元素」收尾 + 模型侧选指令遵循干净的（见 5 章） |
| 7 | token 计费陷阱 | GPT Image 2 low/high 差 35 倍，账单爆炸 | 显式指定 quality 参数，中档起步按需升档 |
| 8 | 风格漂移 | 同一批题混用模型，插图像拼凑的 | 全系列固定一个模型；或用首图做参考图锁风格（Seedream 参考图免费、NB2 支持 20 张参考） |
| 9 | 中文直译翻车 | 国际模型理解「上底」「腰」等数学术语失败 | 机翻时把数学术语展开成几何描述（trapezoid with parallel top and bottom sides） |
| 10 | 合规与网络 | 国际模型国内直连不稳，聚合平台质量参差 | 生产环境优先国产直连；国际模型走正规聚合渠道并留存备用路线 |

### 7.2 一个重要的预期管理

MathGen 的数据说明：目前 **没有任何模型** 能在严格判卷下稳定通过数学可视化（最强 42%）。教学插图的验收标准应当是「 **视觉上正确** 」（看起来平行、数量对、方向对），而不是「几何证明级正确」——后者只有代码路线能保证。别拿游标卡尺量 AI 画的梯形，会气到自己 🤷

## 8. 总结与决策树 ✅

### 8.1 一句话结论

- **效果上限首选**：Nano Banana Pro（几何结构 + 推理构图最强）
- **计数与图表首选**：GPT Image 2（counting 60% 第一 + 统计图比例最忠实）
- **扁平风格首选**：Recraft V4.1（唯一真扁平 + 可输出 SVG）
- **国产直连首选**：Seedream 5.0 Pro / Lite（综合画质 + 中文母语 + 交互编辑）
- **性价比抽卡**：Qwen-Image-3.0 / CogView-4
- **几何与统计图终极兜底**：LLM 写 SVG / Matplotlib 代码

### 8.2 决策树

```
能否接受海外 API / 聚合平台？
├─ 能
│   ├─ 图里几何关系是硬约束（梯形、角、钟面角）→ Nano Banana Pro
│   ├─ 数量敏感（数苹果）或图表敏感（条形图）→ GPT Image 2 (high)
│   ├─ 极致扁平风 / 需要 SVG 二次编辑 → Recraft V4.1（Vector 版）
│   └── 以上都要 → 分层路由（见 6.1）
└─ 不能（必须国内直连）
    ├─ 效果优先 → Seedream 5.0 Pro
    ├─ 批量性价比 → Seedream 5.0 Lite / Qwen-Image-3.0
    └─ 严格统计图 → 代码兜底线（SVG / Matplotlib）
```

### 8.3 针对本场景的最终推荐

结合「效果好一点 + 不是刚好能用就行」的质量要求，我的推荐组合是：

1. **主力**：GPT Image 2 (medium)——五类图全都能打，counting 和统计图两项还是全场第一，¥0.38/张
2. **旗舰补充**：梯形等硬几何题单独路由到 Nano Banana Pro——这一类图是全场景分差最大的地方，值得花 3 倍价钱
3. **风格锁**：全系列固定主力模型 + 参考图，保证 5 类图排版进同一张试卷时不穿帮
4. **国内直连备胎**：Seedream 5.0 Pro——效果档位略低但完整可用，网络受限时的 Plan B
