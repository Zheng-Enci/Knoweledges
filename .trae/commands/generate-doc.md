## ✍️ Markdown 加粗与 Emoji 规范

- `**文本**` 前后必须保留空格，紧贴中文字符会导致渲染失败 ❌
- `**` 闭合后必须加空格再放 emoji，否则 Markdown parser 无法正确闭合加粗（如 `**加粗文本** 🎮` 而不是 `**加粗文本**🎮`） ⚠️

## 🎭 文档幽默风格规范

- 生成的文档需在**合适位置**自然融入幽默表达，让内容生动有趣、吸引读者 👀
- 幽默方式：生动比喻、俏皮话、反差梗、自嘲等，避免低级玩笑和冷场 🤣
- 推荐位置：引言、章节小标题、示例注释、结论等自然节点 🎯
- 原则：幽默为内容服务，不喧宾夺主；技术准确性永远优先，不得因搞笑而失真 ✅
