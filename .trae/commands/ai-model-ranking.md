## 文档放置位置

- **目标目录**：`LLM-大模型技术专栏/`（知识库根目录下）
- **文档编号**：`LLM04`（接续现有 LLM 系列编号，后续执行时取当前最大 LLM 编号 +1）
- **文件命名**：`{编号}-{文档标题}.md`，标题需精炼概括内容（如 `LLM04-2026年AI大模型终极选型指南.md`）
- **参考文档模板**：严格遵循 `标准文档`下的的文档模板风格（仅保留格式框架，移除 HTML 注释和模板说明）
- **资源目录**：无需创建 resources 目录（本文档无外部资源引用）

## 前置条件

1. 获取当前时间：执行 `Get-Date -Format "yyyy年MM月dd日"` 获取实时时间
2. 联网搜索：分别搜索写代码和写文本方向的模型 benchmark 排名、API 定价和综合评价
3. **数据来源声明**：文档中所有推荐理由、benchmark 数据、API 定价、综合评价等核心信息，**必须**基于联网搜索获取的最新资料总结得出，不得凭空编造
4. **数据时效性**：必须优先采用搜索到的当前最新数据（如截至撰写日的最新 benchmark 排名、最新 API 定价），在文中注明数据截止时间。
5. **数据充分性**：如果搜索到的数据不够支撑推荐结论，必须继续搜索补充数据，直到搜索不到新数据为止。

## 范围与约束

- **覆盖范围**：国内模型
- **可用性要求**：仅选择可通过公开 API 或网页端直接使用的模型（排除仅企业合作、无公开 API、或无法实际调用的模型）
- **性价比标准**：综合参考 API 定价（输入/输出单价）与性能表现的平衡，而非单纯看价格

文档中每个推荐必须包含：

- 推荐理由（benchmark 数据支撑）
- 适用的公开 API 或网页端
- 参考定价

## 输出格式

文档末尾需包含以下格式的总结段落：

```
写代码性价比最高：xxx
写代码综合最强：xxx
写文本性价比最高：xxx
写文本综合最强：xxx
```
