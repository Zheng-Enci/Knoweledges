## 📌 适用场景

执行本 command 时，自动完成「找最新文档 → 清洗标题 → 处理图片 → 发布掘金 → 发布 CSDN」全流程 🚀
全程使用**内置浏览器**（browser / Chrome DevTools MCP）操作，不使用平台 API、不修改原文档 ✅

## ✅ 前置条件

1. **🕐 获取当前时间**：执行 `date "+%Y-%m-%d %H:%M"`（Git Bash）
2. **🌐 浏览器就绪**：打开浏览器，分别确认**掘金**（`https://juejin.cn`）与 **CSDN**（`https://www.csdn.net`）已登录
   - 未登录时调用 `browser_waiting_for_user_interaction`，请用户手动完成登录后继续 🔐
3. **📄 发布前确认**：把「标题 / 专栏 / 标签 / 目标平台」汇总给用户，**用户确认后**才点击发布 ⚠️

## 1️⃣ 定位最新文档

在项目根目录执行（Git Bash）：

```bash
find . -name "*.md" \
  -not -path "./.trae/*" \
  -not -path "./.git/*" \
  -not -path "./标准文档/*" \
  -not -path "*/resources/*" \
  -not -name "README.md" \
  -not -name "*url链接目录*" \
  -not -name "*目录.md" \
  -printf "%T@ %TY-%Tm-%Td %TH:%TM %p\n" \
  | sort -rn | head -n 5
```

- 🥇 取**修改时间最新**（mtime 最大）的一篇业务文档作为本次发布对象
- 📋 输出前 5 名候选及时间，向用户报告最终选中的文档及理由
- 🚫 排除项：`.trae/`、`标准文档/`、`resources/`、`README.md`、各类 `url链接目录`、临时草稿与 `.rendered.html`

## 2️⃣ 解析标题与专栏

| 字段 | 取值规则 | 示例 |
|------|----------|------|
| **专栏名** | 文档所在**文件夹名**（原样保留） | `LLM-大模型技术专栏` |
| **文章标题** | 文件名去掉扩展名 + **去掉开头编号前缀** | `LLM23-LangChain与LangGraph区别-20260929.md` → `LangChain与LangGraph区别-20260929` |

- 🔢 编号前缀正则：`^[A-Za-z]{0,4}[0-9]+[A-Za-z0-9]{0,6}[-_ ]+`
- 🧪 对照示例：
  - `J1C-IDE选择与使用-...` → `IDE选择与使用-...`
  - `09aaa-LayerNorm是什么？` → `LayerNorm是什么？`
  - `@Bean注解基础入门-...` → `@Bean注解基础入门-...`（无编号，保持不变）
  - `为什么学习Java-...` → `为什么学习Java-...`（无编号，保持不变）
- 🏷️ 标签建议：从专栏名与正文提取 2-4 个技术关键词（掘金必选分类 + 至少 1 个标签，CSDN 建议 1-5 个标签）

## 3️⃣ 生成发布稿（不改原文档）

在临时目录生成发布副本，原文档**只读不写** 🔒

1. **✂️ 去掉正文首个一级标题**：若正文首行是 `# 与标题相同/相近的 H1`，删除该行，避免平台标题与正文标题重复
2. **🖼️ 本地图片转 GitCode Raw URL**：按 `.trae/rules/GitCode图片URL转换规范.md` 转换
   - 基础地址：`https://raw.gitcode.com/ZhengEnCi/knoweledges/raw/master/`
   - `resources/P2L/photo/xx.png` → `https://raw.gitcode.com/ZhengEnCi/knoweledges/raw/master/Python-基础技术/resources/P2L/photo/xx.png`
   - 路径统一正斜杠 `/`，中文与空格做完整 URL 编码 ⚠️
3. **🧾 正文其余内容原样保留**：不润色、不删改段落、不调整结构 🚫
4. **🧹 发布完成后删除临时发布稿**（中间产物不留存）

## 4️⃣ 图片渲染兜底（重点）⚠️

GitCode Raw 图片首次访问可能空白或返回占位图，必须验证后再发布：

1. 在浏览器**新标签页逐个打开**发布稿中的 GitCode 图片 URL
2. 等待图片真正加载完成（必要时**手动点击/刷新一次**触发 GitCode 渲染）
3. 回到编辑器，刷新预览或重新粘贴该图片，确认编辑器内**图片可见**
4. 若多次仍无法渲染：改为在编辑器中**直接上传本地图片**，替换该处外链
5. ✅ 所有图片确认可见后，才允许进入发布提交

## 5️⃣ 发布到掘金

1. 打开 `https://juejin.cn/editor/drafts/new?v=2`
2. 填入**文章标题**（已去编号）、**正文**（Markdown 模式粘贴）
3. 选择**分类**、填写**标签**（掘金必填，否则无法发布）
4. 打开「发布」面板 → 选择**专栏**，专栏名 = 文件夹名
   - 不存在则新建同名专栏：创作中心 → 专栏管理 → 新建专栏，名称填文件夹名 ✅
5. 按第 4 节完成图片检查 → 点击发布
6. 记录发布后的文章 URL 🔗

## 6️⃣ 发布到 CSDN

1. 打开 `https://editor.csdn.net/md/`
2. 填入**文章标题**（已去编号）、**正文**（Markdown 模式粘贴）
3. 勾选**原创**，填写 1-5 个标签
4. 选择**分类专栏**，专栏名 = 文件夹名
   - 不存在则新建同名专栏：`https://mp.csdn.net/mp_blog/manage/column` → 新建专栏 ✅
5. 按第 4 节完成图片检查 → 点击发布
6. 记录发布后的文章 URL 🔗

## 7️⃣ 发布后汇报

以表格输出结果：

| 平台 | 文章标题 | 专栏 | 状态 | 链接 |
|------|----------|------|------|------|
| 掘金 | {去编号标题} | {文件夹名} | 已发布 / 失败 | {URL} |
| CSDN | {去编号标题} | {文件夹名} | 已发布 / 失败 | {URL} |

- ❌ 任一平台失败时，说明失败步骤与页面提示，不重复盲目重试
- 🔁 平台已存在同名文章时，**不重复创建**，报告已有链接并询问是否覆盖更新

## ⚠️ 约束

- 🚫 不修改原文档内容、不改文件名、不移动文件
- 🚫 不自动 `git push`
- 🚫 不编造标签、分类或专栏名
- ⚠️ 发布属于不可逆操作，**用户确认后方可提交**
