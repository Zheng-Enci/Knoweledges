# 模型推荐（ai-model-best-value）

> 📄 **完整规范参考**：本 skill 的模型范围、数据源、三榜结构、评分公式、输出格式全部以 [ai-model-best-value.md](../../commands/ai-model-best-value.md)（本仓库 command 文件）为准。本文件作为入口与铁律兜底，执行时先读该 command 文件。

## 目标

生成一篇国内 AI 模型排行文档，包含**三个独立榜单**：语言最强 / 语言最具性价比 / 多模态最强。

## 前置条件

1. 读 `ai-model-best-value.md` command 文件全文。
2. 确认用户指定的模型范围（以其输入为准，不得擅自增删）。
3. 联网搜索各家模型在官方定价页的 API 定价（来源 + 检索日期）。

## 执行主流程

- **① 确定模型范围**：以用户输入为准，不增删。
- **② 收集定价**：一律联网搜索原厂官方页定价，禁编造，标注「联网搜索（来源 + 检索日期）」。
- **③ 计算成本**：`综合成本 = 输入单价 × 0.75 + 输出单价 × 0.25`。
- **④ 计算性价比**：`性价比 = 得分 ÷ 综合成本`；榜单②乘「速度系数」（归一 0–1，最快 = 1.0）。
- **⑤ 生成三榜**：语言最强 / 语言最具性价比 / 多模态最强，各自独立。
- **⑥ 风格与输出**：按 command 的文档风格与输出格式落地。

## 关键铁律（不可省略）

- 🔒 **模型范围以用户输入为准**，不得增删。
- 💰 **API 定价一律联网搜索**原厂官方页，禁编造，须标「来源 + 检索日期」。
- 🧮 **成本公式**：`输入 × 0.75 + 输出 × 0.25`。
- 🏆 **性价比**：`得分 ÷ 综合成本`；榜单②再乘速度系数（归一 0–1）。
- 🚫 **不评比**图片/视频/语音生成类模型。
- 🔒 **模型须遵循项目级 rules 文件**作为入选门槛（「听话」要求）。
- 🔒 **自动 git 提交**（英文 message），禁止 push。

## 交付汇报

输出三榜文档路径，并列出所用定价来源与检索日期。
