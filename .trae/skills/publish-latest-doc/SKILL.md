# 发布最新文档（publish-latest-doc）

> 📄 **完整规范参考**：本 skill 的详尽操作步骤、平台问题库、图片生成参数、选曲规范、错误处理全部以 [publish-latest-doc.md](../../commands/publish-latest-doc.md)（本仓库 command 文件）为准。本文件作为入口与兜底检查清单，执行时先读该 command 文件，再按步骤执行。

## 目标

把知识库「最新一篇文章组」（母稿 + 抖音变体）分发到 **掘金 + 抖音** 两个平台位，全部发布成功。CSDN 默认跳过（用户已确认「跳过csdn吧」），如需发布以用户最新指示为准。

## 前置条件检查（先读 command 文件）

1. **先读问题库**：通读 command 文件第 8️⃣ 节「平台问题库」，把命中本组变体的问题抄进临时 checklist。
2. **获取当前时间**：`date "+%Y-%m-%d %H:%M"`。
3. **浏览器就绪**：确认掘金 `https://juejin.cn`、抖音 `https://creator.douyin.com` 已登录；未登录才调用 `browser_waiting_for_user_interaction` 请用户扫码。
4. **变体齐备**：`-抖音.md` 存在且 front-matter 完整。

## 执行主流程

- **① 定位文章组**：按 command 第 1️⃣ 节 `find` 命令取母稿 mtime 最新一篇，推导变体路径。
- **② 解析标题/专栏/front-matter**：按第 2️⃣ 节，串台校验变体 `source` 必须等于母稿完整文件名。
- **③ 生成封面图**：按第 2️⃣-2 节，横版 2560x1440（掘金）+ 竖版 3:4（抖音卡片，`P01` 兼封面），用 `.trae/commands/生成图片.md` 或本机 Python + Pillow。
- **④ 生成发布稿**：按第 3️⃣ 节，剥离 front-matter、去首个 H1、本地图片转 GitCode Raw URL；抖音额外做纯文本化。
- **⑤ 平台摘要**：按第 3️⃣-2 节，掘金 ≤100 字、变体用 front-matter `summary` 压缩。
- **⑥ 图片/资源预热**：按第 4️⃣ 节与 4️⃣-2 节，验证 GitCode 图片与配套资源 Raw URL 可访问。
- **⑦ 发布掘金**（母稿）：按第 5️⃣ 节。
- **⑧ 发布抖音**（变体）：按第 7️⃣ 节，正文一页一卡转 1080x1440 卡片图，标题 ≤20 字、描述 ≤200 字 + 话题、**必须选背景音乐**。
- **⑨ 发布后汇报 + 更新问题库 + git**：按第 9️⃣ 节表格汇报；新踩的坑立即写入问题库；所有 git add/commit 自动执行，禁止 push。

## 关键铁律（不可省略）

- 🔒 **正文零改动**：发布提交的正文必须与对应 `.md` 逐字一致，只做排版类处理（加粗/着色/分页/断行/表格转图/抖音纯文本化）。要改文字回文档改。
- 🎵 **抖音必须配背景音乐**：未选中曲目禁止点「发布」。
- 🛑 **任一平台失败即停**：按「掘金 → 抖音」顺序，失败后不再发起后续平台，如实上报。
- 🧠 **问题必须回写**：遇到新 issue 并解决后立即更新 command 第 8️⃣ 节问题库；只汇报不记录视为未完成。
- ⚠️ **MCP workspace roots 限制**（问题库第 33 条）：要上传的封面/卡片图先复制到 `C:\Users\zheng\AppData\Local\Temp\`，再 `upload_file` 该绝对路径；`evaluate_script` 脚本用 `function` 参数内联。

## 交付汇报

按 command 第 9️⃣ 节格式输出 3 行表格（掘金/CSDN/抖音，缺项写「已跳过」），并附问题库更新说明。
