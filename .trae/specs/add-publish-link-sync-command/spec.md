# 发布链接同步指令 Spec

## Why
文档发布到掘金和 CSDN 后，链接需要手动复制到各专栏的 URL 链接目录，容易遗漏，也容易把「审核中 / 未通过」的文章误记为已发布。需要一条指令自动抓取最新发布文章的链接，并只写入审核通过的链接。

## What Changes
- 新增 `.trae/commands/sync-publish-links.md` 指令文件
- 复用 `publish-latest-doc` 的「最新文档定位」与「标题去编号」规则，保证两条指令口径一致
- 使用内置浏览器访问掘金创作中心与 CSDN 内容管理，抓取最新发布文章的链接与审核状态
- 仅将**审核通过**的链接写入对应专栏（文件夹名）的 `*url链接目录*.md`，按文件既有格式追加并去重
- 审核中、未通过、未找到文章、未找到专栏目录时，明确报告且**不写入**

## Impact
- Affected specs: 无
- Affected code: `.trae/commands/sync-publish-links.md`（新增）、各专栏 `*url链接目录*.md`（仅追加，不改动既有条目）

## ADDED Requirements

### Requirement: 定位目标文档
指令 SHALL 以「最新修改的业务文档」为锚点，确定本次要同步链接的文档，并向用户确认目标。

#### Scenario: 成功定位
- **WHEN** 用户执行该指令
- **THEN** 按文件 mtime（修改时间）倒序选出最新业务文档，排除 `.trae/`、`标准文档/`、`resources/`、`README.md`、`*url链接目录*`、`*目录.md`、`.rendered.html`，并输出前 5 名候选供核对
- **AND** 依据文件名计算去编号标题（正则 `^[A-Za-z]{0,4}[0-9]+[A-Za-z0-9]{0,6}[-_ ]+`），依据父文件夹名计算专栏名

#### Scenario: 浏览器未登录
- **WHEN** 掘金或 CSDN 未登录
- **THEN** 调用 `browser_waiting_for_user_interaction` 请用户登录，登录完成后再继续

### Requirement: 平台链接抓取
指令 SHALL 在内置浏览器中分别从掘金与 CSDN 的内容管理列表，按去编号标题匹配最新发布文章，并取得文章 URL。

#### Scenario: 掘金抓取成功
- **WHEN** 掘金创作中心的文章列表中存在标题匹配的文章
- **THEN** 记录该文章 URL，并确认列表中无「审核中 / 未通过」标识

#### Scenario: CSDN 抓取成功
- **WHEN** CSDN 内容管理中存在标题匹配的文章
- **THEN** 记录该文章 URL，并读取列表中的状态字段

#### Scenario: 平台未找到匹配文章
- **WHEN** 某平台不存在标题匹配的文章
- **THEN** 不写入该平台链接，向用户报告「未找到匹配文章」

### Requirement: 审核状态校验
指令 SHALL 只把审核通过的文章链接写入链接目录；非通过状态必须报告给用户。

#### Scenario: 审核通过
- **WHEN** CSDN 列表状态为「已发布」，或掘金文章页可正常访问且无审核中 / 未通过提示
- **THEN** 判定为审核通过，允许写入链接目录

#### Scenario: 审核中或未通过
- **WHEN** 平台显示「审核中」「未通过」「审核不通过」等状态
- **THEN** **禁止写入**链接目录，并向用户报告文章标题、平台、当前状态与后续建议

### Requirement: 写入专栏链接目录
指令 SHALL 把审核通过的链接写入该专栏（文件夹名）下的链接目录文件，遵循文件既有格式并去重。

#### Scenario: 链接目录已存在
- **WHEN** 专栏文件夹下存在 `*url链接目录*.md`
- **THEN** 识别其现有格式（Markdown 表格或 `## 文档名` + 列表），按同一格式追加；同一平台同一 URL 已存在时不重复写入
- **AND** 若文件含「更新记录」，追加本次更新条目（日期 + 文档名 + 平台）

#### Scenario: 链接目录不存在
- **WHEN** 专栏文件夹下无链接目录文件
- **THEN** 以文档编号前缀创建 `{编号前缀}00-url链接目录.md`（无编号前缀时创建 `00-url链接目录.md`），使用标准表格模板写入

#### Scenario: 无法映射专栏
- **WHEN** 平台上文章所属专栏在本地找不到同名文件夹
- **THEN** 停止写入并报告平台专栏名，由用户确认映射关系，禁止自行猜测目录

### Requirement: 结果汇报
指令 SHALL 在结束时以表格汇报各平台处理结果。

#### Scenario: 汇报内容
- **WHEN** 抓取与写入流程结束
- **THEN** 输出「平台 / 文章标题 / 审核状态 / 是否写入 / 链接」表格；失败项说明失败原因，不重复盲目重试
